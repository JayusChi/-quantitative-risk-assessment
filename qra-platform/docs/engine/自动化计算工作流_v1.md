# 自动化计算工作流 v1

## 1. 目标

把原来的“人工选择命令并逐个运行脚本”收敛成一个可审计任务：输入一份QRA案例JSON和任务配置，自动完成输入校验、计算项调度、结果派生、图表生成和输出登记。

自动化层不修改`QRAEngine`内的失效频率、泄漏、扩散、火灾爆炸、人员伤害、IR、F-N和PLL公式；它只选择已登记的计算配置并组织输出。

## 2. 执行流程

```text
任务配置 + 输入JSON
        |
        v
输入校验 --错误--> validation.json + BLOCK清单
        |
        v
计算项注册表分派
  |-- human-qra ----------> AQ/T 3046人员域QRA主链
  |-- gbt34346-annex-c ---> GB/T 34346附录C独立校核
  |-- synthetic-chain ----> 合成后果回归链
  `-- golden-aggregate ---> 聚合层黄金回归
        |
        v
完整计算结果JSON
        |
        v
风险矩阵JSON/CSV + 7张SVG图表 + HTML总览
        |
        v
manifest.json（输入哈希、运行项、输出路径、文件哈希）
```

## 3. 任务配置

示例位于`inputs/自动化任务_人员域QRA.json`。关键字段：

| 字段 | 含义 |
|---|---|
| `schema_version` | 自动化配置结构版本，当前固定为`1.0.0` |
| `job_id` | 用户可读任务编号 |
| `input` | QRA输入JSON；相对路径按配置文件所在目录解析 |
| `calculations` | 按顺序选择计算项，可一次运行多个 |
| `outputs.directory` | 独立任务输出目录 |
| `outputs.primary_calculation` | 多个计算结果中用于风险矩阵和图表的主结果 |
| `outputs.risk_matrix` | 是否输出矩阵JSON和CSV |
| `outputs.charts` | `all`或图表ID数组 |
| `outputs.html_dashboard` | 是否输出HTML总览 |
| `risk_matrix_criteria` | 可选的项目矩阵阈值覆盖；必须保留可追溯准则ID |

## 4. 风险矩阵的定量含义

参考报告的定量明细满足`PLL = 频率 x N_q`。本工作流据此定义：

- 可能性轴：管段起始失效频率，单位`1/年`；
- 后果轴：等效后果人数`N_q = 管段PLL/管段起始失效频率`，单位`人/次失效`；
- 管段主风险值：`PLL = sum(场景频率 x 场景死亡人数)`，单位`期望死亡人数/年`。

默认5x5阈值是测试和展示配置，状态固定标记为`DISPLAY_ONLY_NOT_ACCEPTANCE_CRITERION`。它不能替代个人风险IR准则，也不能替代项目批准的F-N接受曲线。正式项目若要把矩阵用于管理分级，必须单独批准矩阵边界并将其作为版本化项目准则输入。

## 5. 图表与参考报告的对应关系

| 自动图表 | 参考报告中的表达形式 | 当前QRA数据来源 |
|---|---|---|
| 管段失效频率构成 | 各单元频率及威胁构成堆叠柱图 | `loc_frequency.mechanism_contribution` |
| 管段PLL排序 | 定量风险明细及排序 | `segment_risk.ranking` |
| 风险矩阵 | 失效可能性-后果矩阵 | 失效频率等级和`N_q`等级 |
| 沿线风险剖面 | 沿里程风险等级与状态耦合图 | 起止里程、展示色带和PLL |
| 个人风险 | 风险点与准则对比 | 各人口单元IR及参考阈值 |
| F-N曲线 | 社会风险结果图 | `societal_risk.fn_curve` |
| 融合优先级气泡图 | 多指标优先级气泡图 | IR、`N_q`等级、失效频率和PLL |

当前引擎尚未实现正式的蒙特卡洛不确定性传播，因此不会仿制参考报告中的P05-P95区间图；在参数分布、抽样规则和验证方法获批前，不生成伪不确定性结果。当前也没有“措施后”重新计算输入，所以不会自动生成措施前后降幅预测图；该图应由两个独立QRA任务结果的对比模块生成。

## 6. 自动化边界

- 自动化运行成功不等于允许签发正式报告；必须检查结果中的`formal_report_allowed`和阻断项。
- 合成测试输入、未批准的K_j、临时物性参数或未完成独立验证的物理模型仍会阻止正式签发。
- HTML和SVG是计算结果展示件，不是最终正式PDF报告；后续结果处理层可读取同一JSON和SVG生成正式报告。
- 每次运行独立保存`manifest.json`和SHA-256，便于输入、模型结果和输出文件追溯。
