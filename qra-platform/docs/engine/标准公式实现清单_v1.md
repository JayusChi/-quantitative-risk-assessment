# 人员域 QRA 标准公式实现清单 v1

版本日期：2026-08-05  
适用对象：陆上埋地高压天然气输送管道人员域 QRA  
主标准：SY/T 6891.2—2020  
后果调用：AQ/T 3046—2013  

## 状态定义

| 状态 | 含义 |
|---|---|
| `IMPLEMENTED_UNIT_TESTED` | 已编码并有独立边界/数值测试 |
| `IMPLEMENTED_PROVISIONAL_VALIDATION` | 已编码、接入主链并通过单元/集成测试，但仍需独立基准案例或曲线复核 |
| `IMPLEMENTED_NOT_INTEGRATED` | 公式已编码，但尚未接入正式空间场景链 |
| `PENDING_MODEL_DECISION` | 标准给出多种方法或资料性方法，需批准选型 |
| `BLOCKED_PARAMETER_LIBRARY` | 公式明确，但缺正式参数库 |
| `BLOCKED_REFERENCE_DATA` | 依赖图表、外部曲线或标准未给全的关系 |

## 6. 正式模型启用条件

默认人员域模型现为 `IMPLEMENTED_STANDARD_FORMULAS_PROVISIONAL_VALIDATION`。它已经能够使用测试数据完成泄漏—扩散—火灾/爆炸—人员伤害—IR/F-N/PLL—管段排序全链计算，但只有在以下条件全部满足后，才能改为 `RELEASED`：

1. 首版正式失效频率库和孔径比例通过适用性审查；
2. 62项必需指标观测槽100%覆盖，所有使用值均有责任人、日期、质量和来源证据；
3. 各失效机理K_j采用经批准的项目因子，或其变量与系数由适用失效数据校准并完成独立验证；
4. 完全破裂、隔离、上下游补气和放空的瞬态源项模型冻结；
5. 高压天然气近场射流到远场扩散的模型选择和切换条件冻结；
6. 喷射火与VCE模型完成参数库、曲线数据化和独立黄金案例；
7. 建筑物/室内外人口、占用时段和防护修正数据可用；
8. IR网格收敛、泄漏点收敛和至少一个完整区段人工复核通过；
9. 风险可接受准则已批准，或明确只计算不判定。
