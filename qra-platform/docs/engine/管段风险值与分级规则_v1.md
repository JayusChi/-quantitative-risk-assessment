# 管段风险值与分级规则 v1

版本日期：2026-08-05  
适用对象：陆上油气输送管道人员域QRA  

## 1. 管段风险值

管段风险值采用潜在生命损失PLL：

```text
R_segment = PLL_segment = Σ_s (f_s × N_s)
```

- `f_s`：属于该管段的事故结果场景`s`的年频率，单位`/year`；
- `N_s`：该场景的期望死亡人数；
- `R_segment`：管段期望死亡风险，单位`expected fatalities/year`。

来源为AQ/T 3046—2013式(15)。管道总PLL等于全部管段PLL之和。

## 2. 排序字段

引擎同时输出四种互不替代的顺序：

1. `risk_value_rank`：按管段PLL降序，表示对管道总人员风险的贡献；
2. `risk_density_rank`：按`PLL/管段长度`降序，减少管段长度差异造成的偏置；
3. `individual_risk_rank`：按该管段对受体点最大个人风险贡献降序；
4. `maximum_consequence_rank`：按单一场景最大期望死亡人数降序。

“高后果”不等于“高风险”：最大后果不乘频率，PLL已经包含频率。

## 3. 标准风险等级

采用GB/T 34346—2017附录C图C.2的个人风险参考值：

| 风险等级 | 判定条件 | 含义 |
|---|---:|---|
| `HIGH_UNACCEPTABLE` | `IR > 1×10^-3 /year` | 高风险，不可接受，必须降低 |
| `MEDIUM_ALARP` | `1×10^-5 < IR ≤ 1×10^-3 /year` | 中风险，开展成本效益分析并尽可能降低 |
| `LOW_ACCEPTABLE` | `IR ≤ 1×10^-5 /year` | 低风险，维持控制并持续监测 |

图C.2明确将数值标为“参考值”。当项目合同、属地法规或主管部门规定了更严格或更具体的准则时，必须使用经批准的版本化准则集替换，不能擅自取宽松值。

## 4. 社会风险边界

引擎按标准计算管道及各管段F-N曲线，但当前不自动给F-N判定等级。原因是本项目尚未批准一套数值F-N可接受曲线；SY/T 6891.2—2020图5是示意图，不能直接冻结为强制阈值。

## 5. 输出解释

- 标准风险等级依据个人风险IR；
- 管段治理优先级首先参考`risk_value_rank`和`risk_density_rank`；
- 对低频严重事件，同时参考`maximum_consequence_rank`；
- 正式报告应同时展示IR等值线、F-N曲线、管道PLL和管段风险表，不得只用单一排名代替完整风险评价。

## 6. GB/T 34346附录C独立校核值

引擎另行输出附录C式(C.42)的管段风险：

```text
R = PoF × FI × C × Dp
```

- `PoF`：失效概率，`/(km·year)`；
- `FI`：点火概率；
- `C`：人员伤害后果面积，`m²`；
- `Dp`：后果区人口密度，`person/m²`；
- `R`：风险密度，`expected fatalities/(km·year)`。

该风险值可用于管段排序和与完整QRA结果交叉校核，但不能用其替代IR等值线和F-N曲线，也不能直接套用个人风险的`1E-5/1E-3`阈值对`R`判级。
