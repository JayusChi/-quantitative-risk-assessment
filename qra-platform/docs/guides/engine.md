# 计算引擎

本目录是天然气输送管道人员域QRA计算引擎，当前版本为`0.6.0`。当前同时提供“动态数据驱动流程”和兼容的“固定计算配置流程”。新项目应优先使用动态流程：输入不满足完整QRA时，不再阻断整个任务，而是执行所有数据条件已满足的独立节点，并通过自适应证据定量风险模型形成风险值、排序、矩阵、不确定性带和补数清单。

## 动态数据驱动流程（推荐）

动态流程按以下顺序工作：

```text
任意部分输入JSON
→ 识别数据段和17组工程指标
→ 检查每个计算节点的字段合同
→ 自动生成依赖图DAG
→ 执行所有可运行节点
→ 以现有证据形成定量风险值；完整数据时自动升级为完整人员QRA
→ 隔离单节点错误
→ 输出风险排序、矩阵、不确定性带、节点JSON、网页和补数清单
```

当前已经拆分并登记11个节点：

| 节点 | 是否可独立得到部分结果 | 主要输入 | 输出 |
|---|---|---|---|
| `data_inventory` | 是 | 任意JSON | 数据类别与顶层数据段盘点 |
| `indicator_coverage` | 是 | 任意JSON | 17组、246项指标覆盖率 |
| `segment_geometry` | 是 | 管段编号、里程、长度 | 管段结构化表和长度图 |
| `failure_frequency` | 是 | 管段、频率库、K_j输入 | 分管段/机理/孔径失效频率 |
| `leak_point_discretization` | 是 | 管段坐标、离散间距 | 泄漏点和数量图 |
| `aqt3046_source_term` | 是 | 压力、温度、管径、阀间距、物性 | 四类泄漏释放率 |
| `jet_fire_thresholds` | 是 | 源项结果、燃烧热、辐射分数 | 5/12.5/37.5 kW/m²距离 |
| `gbt34346_annex_c` | 是 | 附录C所需项目参数 | 独立校核结果和排序图 |
| `adaptive_evidence_qra` | 是，风险兜底节点 | 管段及当前可用的完整性、运行、高后果目标数据 | 每段PLL筛查估计、上下界、排序和证据追踪 |
| `human_qra` | 否，属于高阶组合节点 | 频率、泄漏点、源项、气象、点火、人口等 | IR、F-N、PLL、管段排序 |
| `risk_matrix` | 是 | 优先使用完整人员QRA，否则使用证据定量风险 | 矩阵JSON/CSV和报告图表 |

自动识别全部可运行节点：

```powershell
python -m qra_engine dynamic `
  --input workspace\inputs\部分输入_10类数据.json `
  --output-dir workspace\outputs\客户A动态结果
```

用户只要求某个结果时，可以选择目标；系统会自动加入依赖节点：

```powershell
python -m qra_engine dynamic `
  --input 客户数据.json `
  --targets failure_frequency `
  --output-dir workspace\outputs\仅失效频率
```

也可以使用可复用配置：

```powershell
python -m qra_engine dynamic --config workspace\inputs\动态任务_自动匹配10类数据.json
```

动态输出目录：

```text
动态任务目录/
├─ dynamic_manifest.json      节点状态和全部输出文件哈希
├─ execution_plan.json        数据匹配后生成的DAG执行计划
├─ capability_report.json     可得结果、不可得结果、缺失字段和补数建议
├─ report_dashboard.html      结论总览、管段排序、风险图谱、算法追踪和补数清单
├─ nodes/                     每个已完成节点的独立标准JSON
├─ charts/                    仅为已完成节点生成的SVG图表
└─ derived/                   始终生成当前风险层级的风险矩阵JSON/CSV
```

部分数据缺少气象或点火模型时，完整人员QRA节点仍会跳过，但`adaptive_evidence_qra`会使用当前可用的指标和模型先验计算管段PLL筛查估计，`risk_matrix`继续生成。结果在`capability_report.json.risk_result.result_tier`中标记为`EVIDENCE_CONDITIONED_SCREENING_ESTIMATE`；数据达到完整QRA条件时自动升级为`FULL_SPATIAL_HUMAN_QRA`。详细架构见[动态计算节点与数据能力规划](../engine/动态计算节点与数据能力规划_v1.md)。

“数据类别数”在预检、能力报告和HTML报告中使用同一口径：优先采用并校验 `data_category_manifest.categories`；没有显式清单时采用 `raw_data_categories` 的类别键；两者都没有时，按引擎登记的规范输入组派生。类别数只用于数据盘点，不代表节点一定可运行。

动态网页优先展示最高风险管段、PLL及全线贡献率、主导事故场景、筛查上下界、证据覆盖率和风险驱动项；随后展示PLL排序、沿线风险剖面、风险矩阵、F-N曲线、融合优先级及证据诊断图。输入类别、节点状态和补数清单默认折叠在“计算与数据明细”中，避免工程日志遮挡风险结论。

## 固定计算配置入口（兼容）

自动化层只负责“校验 -> 调度 -> 后处理 -> 输出”，不会改写核心公式。可调度计算项如下：

| 计算项ID | 调用内容 | 适用范围 | 可生成风险矩阵/人员QRA图表 |
|---|---|---|---|
| `validate-input` | 输入完整性与一致性校验 | 所有输入 | 否 |
| `human-qra` | `aqt3046-physical`人员域QRA主链 | 当前正式开发主链 | 是 |
| `gbt34346-annex-c` | GB/T 34346附录C独立校核链 | 辅助校核 | 否 |
| `synthetic-chain` | 合成后果适配器 | 开发回归 | 是 |
| `golden-aggregate` | 预计算结果聚合 | 黄金结果回归 | 否 |

查看机器可读目录：

```powershell
python -m qra_engine catalog
```

直接选择计算项运行：

```powershell
python -m qra_engine automate `
  --input tests\fixtures\qra_synthetic_case_v1.json `
  --items validate-input human-qra `
  --output-dir workspace\outputs\自动化直接运行
```

按可复用任务配置运行：

```powershell
python -m qra_engine automate --config workspace\inputs\自动化任务_人员域QRA.json
```

每个任务目录采用稳定结构：

```text
任务输出目录/
├─ manifest.json                任务、输入哈希、计算项和全部文件哈希
├─ results/
│  ├─ validation.json          输入校验结果
│  └─ human-qra.json           人员域QRA完整结构化结果
├─ derived/
│  ├─ risk_matrix.json         5x5矩阵、阈值、单元格及管段明细
│  └─ risk_matrix.csv          便于Excel/数据库读取的管段矩阵表
├─ charts/
│  ├─ 01_管段失效频率构成.svg
│  ├─ 02_管段PLL排序.svg
│  ├─ 03_风险矩阵.svg
│  ├─ 04_沿线风险剖面.svg
│  ├─ 05_个人风险.svg
│  ├─ 06_FN曲线.svg
│  └─ 07_融合优先级.svg
└─ report_dashboard.html       汇总查看全部图表和正式报告阻断项
```

图表采用参考报告《某管道脱敏阴极保护数据与高后果区定量风险评价分析报告_V1.0》的蓝色报告版式和结果组织方式，但不复制其中的项目数据、结论或半定量权重。自动化风险矩阵使用：

```text
失效可能性 = 管段起始失效频率
等效后果人数 N_q = 管段PLL / 管段起始失效频率
管段风险值 PLL = 失效频率 x N_q
```

5x5矩阵是可配置的展示视图，不是风险接受准则；管段定量排序仍以PLL为主，个人风险判级仍以已登记的IR准则为准，F-N只有在项目批准数值接受曲线后才能判级。任务配置可以通过`risk_matrix_criteria`覆盖矩阵阈值，并在JSON中保留准则ID和状态。详细说明见[自动化计算工作流](../engine/自动化计算工作流_v1.md)。

## 标准依据与使用方式

当前采用“一个主框架、一个人员后果计算标准、一个辅助校核与风险准则”的组合方式；同一个公式只允许有一个明确来源和版本。

| 标准 | 在本引擎中的角色 | 当前使用内容 | 是否进入默认QRA主链 |
|---|---|---|---|
| SY/T 6891.2—2020《油气管道风险评价方法 第2部分：定量评价法》 | 管道QRA主框架 | 管段划分、5/25/100 mm及完全破裂四类失效场景、泄漏点离散、失效频率方法、人员风险评价和结果表达 | 是 |
| AQ/T 3046—2013《化工企业定量风险评价导则》 | 人员后果与风险数学模型 | 气体孔口泄漏、绝热管道破裂、气体扩散、点火事件树、喷射火、闪火、VCE、人员死亡概率、IR、F-N和PLL | 是，由SY/T 6891.2人员后果分析链调用 |
| GB/T 34346—2017《基于风险的油气管道安全隐患分级导则》 | 独立辅助计算链和个人风险参考准则 | 附录C失效概率、四类泄漏、喷射火后果面积、管段人员风险；图C.2个人风险参考阈值 | 默认主链只使用图C.2参考准则；完整附录C通过`gbt34346-annex-c`单独运行 |
| GB/T 27921—2023《风险管理 风险评估技术》 | 上位风险管理方法参考 | 风险识别、分析、评价和记录的一般原则 | 否，不作为泄漏或后果数值公式来源 |

以下文件虽然位于标准文档库中，但没有被混入当前人员域QRA主链：SY/T 6891.1—2012是半定量评价方法；GB/T 26610系列面向承压设备基于风险的检验，后续可用于设备完整性或检验策略模块，但当前不参与管道人员QRA计算。

标准条款到代码、公式状态和正式启用条件的逐项映射见[标准公式实现清单](../engine/标准公式实现清单_v1.md)。

## 指标体系

引擎已建立版本化的[工程指标目录](../../src/qra_engine/model_specs/qra_indicator_catalog_v1.json)，共登记 **246 项**工程数据、模型输入、切段条件和证据字段：**62 项 REQUIRED**（当前适用范围内正式计算的最低必需项）和 **184 项 CONDITIONAL**（只有相应失效机理、设施或场景存在时才触发）。它们不是“246个打分项”，更不能直接相加；QRA的输入关系是：

```text
工程原始数据/证据 → 指标目录校验与管段继承 → 失效机理修正模型K_j
→ 各管段四类泄漏频率 → 泄漏/扩散/火灾爆炸 → 人员死亡概率
→ IR、F-N、PLL和管段排序
```

17个指标组的登记数量如下：

| 指标组 | 总数 | REQUIRED | CONDITIONAL |
|---|---:|---:|---:|
| 项目、文件与数据治理 | 14 | 9 | 5 |
| 管道几何、材料与设计 | 18 | 10 | 8 |
| 施工、焊接与防护设施 | 14 | 0 | 14 |
| 运行工况与介质 | 18 | 4 | 14 |
| 阀室、控制与隔离 | 14 | 4 | 10 |
| 外腐蚀 | 16 | 3 | 13 |
| 内腐蚀 | 14 | 0 | 14 |
| 应力腐蚀与疲劳 | 12 | 0 | 12 |
| 制造及施工缺陷 | 12 | 0 | 12 |
| 第三方损伤 | 16 | 3 | 13 |
| 地质及自然灾害 | 16 | 1 | 15 |
| 检测、检验与完整性 | 16 | 0 | 16 |
| 气象与地形 | 12 | 8 | 4 |
| 人口与受体 | 14 | 6 | 8 |
| 点火源、拥塞与约束 | 12 | 1 | 11 |
| 管理、维护与应急 | 14 | 2 | 12 |
| 后果模型参数与版本 | 14 | 11 | 3 |
| **合计** | **246** | **62** | **184** |

测试案例通过公共字段直接映射、按管段观测和五种管段原型继承三种方式提供数据。每条显式观测包括`value`、`quality`、`as_of`和`source_ref`，使数值、质量等级、基准日和证据来源可以一并审计。覆盖率只说明数据是否存在，不代表该指标已获得权重或一定进入当前模型。

失效频率按SY/T 6891.2附录A的关系组织：`F = Σ(f_j,0 × f_t × K_j(a1,a2,...))`。标准定义了修正函数`K_j`的角色，但没有给出适用于所有管道的统一指标权重。因此引擎实现了两种可审计接口：

- `provided_factors`：使用经项目批准、按管段和失效机理给出的`K_j`；
- `log_linear_calibrated`：使用`K_j = clip(exp(β₀ + Σβᵢ(xᵢ-referenceᵢ)/scaleᵢ), Kmin, Kmax)`，并输出每个变量的贡献轨迹。该函数形式由引擎提供，系数必须用适用失效数据校准和批准，不能把测试系数当成标准权重。

当前20段测试案例对62项必需指标达到100%观测槽覆盖，但数据及`K_j`均为合成测试值，所以仍不能用于真实风险决策或正式报告。

### 1. 管段、场景与频率指标

| 指标 | 单位/形式 | 含义 |
|---|---|---|
| 管段编号、起止里程、长度 | km | 风险计算和排序的最小资产单元 |
| 管径、壁厚、钢级、埋深、投产年份 | mm、m、年份 | 管段基础属性；部分字段已进入公式，其他字段作为后续频率模型接口保留 |
| 失效机理基准频率 | 次/(km·年) | 外腐蚀、内腐蚀、应力腐蚀、制造施工、第三方损伤、自然灾害和误操作基准频率 |
| 管段修正系数`K_j` | 无量纲 | 由已批准的项目因子或校准模型按失效机理生成；当前测试值为合成参数 |
| 泄漏场景频率 | 次/年 | 小孔5 mm、中孔25 mm、大孔100 mm和完全破裂的年频率 |
| 泄漏点位置及频率份额 | m、无量纲 | 默认按50 m间距离散，管段总频率在泄漏点之间守恒分配 |
| 天气联合概率 | 无量纲 | 时段、稳定度、风速和风向的联合概率 |
| 事件树分支频率 | 次/年 | 喷射火、闪火、VCE和安全扩散各分支年频率 |

| 气体浓度及LFL区域 | kg/m³、m | 连续PG烟羽浓度、可燃下限及闪火包络 |

### 3. 人员后果与QRA风险指标

| 指标 | 单位 | 定义或用途 |
|---|---|---|
| 条件死亡概率 | 0～1 | 热辐射Probit、LFL闪火区域、爆炸超压阈值以及室内外修正后的人员死亡概率 |
| 场景死亡人数 | 人 | 昼夜人口、室内外比例与条件死亡概率的乘积和 |
| 个人风险IR | 1/年 | 某受体位置的场景频率×个人死亡概率之和；不乘人口数量 |
| 最大个人风险 | 1/年 | 全部人口单元或监测点中的最大IR及其位置 |
| F-N曲线 | N人、1/年 | 造成不少于N人死亡的事故累计频率 |
| 潜在生命损失PLL | 期望死亡人数/年 | `PLL = Σ(场景频率 × 场景死亡人数)` |
| 管段风险值 | 期望死亡人数/年 | 当前定义为该管段PLL，不再建立跨域加权总分 |
| 管段风险密度 | 期望死亡人数/(km·年) | `管段PLL/管段长度`，用于不同长度管段的辅助比较 |
| 管段风险贡献率 | % | 管段PLL占全线PLL的比例 |
| 主导风险场景 | 结构化场景信息 | 对管段PLL贡献最大的泄漏点、孔径、天气和后果分支 |
| 最大条件后果 | 人、0～1及物理量 | 管段内最大死亡人数、最大死亡概率及对应热辐射/浓度/超压 |
| 管段排序 | 名次 | 分别输出PLL排序、PLL/km排序、最大IR排序和最大后果排序 |

### 4. 当前个人风险分级

默认采用GB/T 34346—2017附录C图C.2的推荐性参考值：

| 个人风险IR | 当前标签 | 处理含义 |
|---|---|---|
| `IR ≤ 1×10⁻⁵/年` | 低风险（可接受） | 维持控制并持续监测 |
| `1×10⁻⁵/年 < IR ≤ 1×10⁻³/年` | 中风险（ALARP） | 开展成本效益分析并将风险降至尽可能低 |
| `IR > 1×10⁻³/年` | 高风险（不可接受） | 必须降低风险后方可接受 |

该数值是推荐性标准中的参考准则，不是对所有项目自动具有强制效力。项目合同、属地法规或主管部门批准了其他准则时，必须替换默认准则。当前尚未批准项目F-N数值可接受曲线，因此引擎计算F-N但不对社会风险自动判级。

### 5. 审计与质量控制指标

每次运行还输出模型ID和版本、输入哈希、结果哈希、泄漏点数量、展开场景数量、起始频率与分支频率守恒误差、数据分类、警告、正式报告阻断原因以及`formal_report_allowed`状态。

### 6. 当前不属于正式物理主链的指标

测试数据还包含财产年期望损失EAL、环境期望释放量/影响面积/恢复时间、供气未供量和用户中断时间。这些指标目前只用于预计算模拟场景的聚合层回归测试，尚未建立与泄漏—扩散—火灾/爆炸物理链相连的正式财产、环境和供气后果模型，因此不得把它们作为当前人员域QRA主链已经完成的能力。

## 当前能力

- 读取并校验246项版本化工程指标定义，统计必需项、条件项、管段观测槽和17组覆盖率；
- 保存指标值的数据质量、基准日期和来源证据，并支持公共观测、逐管段观测与管段原型继承；
- 通过`provided_factors`或`log_linear_calibrated`把指标接入各失效机理`K_j`，输出完整系数与变量贡献轨迹；
- 校验天然气组分、区段、失效频率库、孔径比例、气象联合概率和运行配置；
- 按失效机理、区段修正系数和管段长度计算小孔、中孔、大孔及破裂频率；
- 沿管段离散泄漏点并守恒分配区段频率；
- 展开天气、风向、立即点火、延迟点火、喷射火、闪火、VCE 和安全扩散分支；
- 默认通过 `human.aqt3046.pipeline.v1` 计算真实标准公式的条件死亡概率；
- 聚合个人风险 IR、潜在生命损失 PLL、社会风险 F-N 和区段贡献排名；
- 输出输入哈希、结果哈希、模型版本、频率守恒和警告信息；
- 兼容现有预计算模拟后果数据，作为聚合层黄金回归测试。
- 已接通AQ/T 3046标准公式链：孔口泄漏、两侧绝热破裂初始流量、连续高斯烟羽、LFL闪火、水平喷射火、TNO VCE、室内外人员伤害修正、IR、F-N和PLL；
- 用模型注册状态和正式报告门禁阻止未完成模型被误签发。
- 按AQ/T 3046式(15)计算每个管段的`Σ(场景频率×死亡人数)`风险值，同时输出PLL/km、最大后果和主导场景；
- 按GB/T 34346—2017附录C图C.2参考值输出个人风险`低风险/ALARP/高风险`等级。

## 重要边界

测试适配器 `human.synthetic.spatial.v1` 仍保留为聚合层回归测试，但已不再是默认人员后果模型。任何使用合成频率、合成人口或合成参数的运行都不能签发正式 QRA 报告。

工程指标目录是输入合同和可追溯清单，不是半定量评分表。当前测试案例的`frequency.correction.synthetic_provided.v1`仅验证频率计算接口和20段排序；正式使用必须替换为经批准的项目`K_j`，或用适用失效数据校准`log_linear_calibrated`模型，并完成独立验证。引擎会同时检查必需指标100%覆盖、指标数据非合成、修正模型状态获批，任一条件不满足即阻止正式报告。

人员后果模型 `human.aqt3046.pipeline.v1` 已登记为 `IMPLEMENTED_STANDARD_FORMULAS_PROVISIONAL_VALIDATION`。公式链已经编码、接入并通过单元/集成测试；当前仍因破裂瞬态降压、高压近场扩散基准、图E.1数据化曲线独立验证和生产参数库未批准而禁止正式签发。详细状态见 [标准公式实现清单](../engine/标准公式实现清单_v1.md)。Phast/Safeti 不是运行依赖，只能作为可选的独立对比工具。

管段风险值、排序字段和风险等级的严格定义见 [管段风险值与分级规则](../engine/管段风险值与分级规则_v1.md)。GB/T 34346图C.2给出的是推荐性标准中的参考值；项目批准准则存在时必须覆盖该默认准则。F-N数值可接受曲线尚未批准，因此当前只计算F-N、不自动判级。

## 运行

在本目录执行：

```powershell
python -m qra_engine validate --input tests\fixtures\qra_synthetic_case_v1.json
python -m qra_engine models
python -m qra_engine run --input tests\fixtures\qra_synthetic_case_v1.json --output workspace\outputs\aqt3046_physical_chain_result.json
python -m qra_engine run --profile synthetic-chain --input tests\fixtures\qra_synthetic_case_v1.json --output workspace\outputs\synthetic_result.json
python -m qra_engine run --profile golden-aggregate --input tests\fixtures\qra_synthetic_case_v1.json --output workspace\outputs\golden_aggregate_result.json
python -m qra_engine run --profile gbt34346-annex-c --input tests\fixtures\qra_synthetic_case_v1.json --output workspace\outputs\gbt34346_annex_c_standard_formula_result.json
```

完整主链默认使用 `aqt3046-physical` 配置。`synthetic-chain` 和 `golden-aggregate` 只用于保持既有聚合层黄金结果。

`aqt3046-physical`按泄漏点计算5/25/100 mm孔口泄漏和上下游两侧绝热破裂初始流量；按天气和受体位置计算连续气云浓度、喷射火热辐射、TNO爆炸超压以及个人/社会风险死亡概率。测试文件中的物性、点火源、室内外比例、爆炸源体积和TNO强度均为合成参数。

`gbt34346-annex-c`使用GB/T 34346—2017规范性附录C的定量二级评价公式：C.1～C.3计算失效概率，表C.24确定四类泄漏，C.12～C.15的等价SI实现计算气体泄漏，标准喷射火公式计算37.5 kW/m²距离，C.40～C.43计算后果面积和管段人员风险。该配置的公式是真实标准公式，当前物性、修正因子、点火概率和人口密度仍为合成测试参数；它是独立校核链，不替代SY/T 6891.2完整空间QRA。
