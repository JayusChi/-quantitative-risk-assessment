## 4. 已知限制与后续外部依赖

- 供应商文本接口的 `table_parsing` 结果不保证逐单元格坐标。平台目前将解析出的单元格保守映射到已检测表格的有界网格，标记较低置信度并保留人工复核入口；必须用真实表格样本验证。
- 后台重提取状态持久化到数据库，进程重启后会把中断任务重新排队；当前不是外部分布式任务队列。
- 当前真实资料覆盖标准文档首页，不等同于管道台账、检测报告、扫描表格和冲突多来源资料的完整业务分层抽样；是否需要补充这些类别由 QRA 负责人决定。
- 正式业务验收仍需要 QRA 负责人逐批批准草案标签、关键字段和阈值，并明确冲突样本的补充数量。
