## 已完成的工程改动

1. 黄金集评估器支持在显式 `--include-draft` 模式下运行 AI 草案，同时强制正式批准门禁失败。
2. 增加按文档类别、字段类别和匿名化单文档统计。
3. 增加耗时、输入/输出/总 Token、人工复核时间及其记录完整性门禁。
4. 没有冲突样本时，冲突识别率改为“不可评估”，不再把 `0/0` 误报为 100%。
5. 通用在线提取自动字段上限由 80 提升为默认 256，并可通过 `QRA_EXTRACTION_AUTO_FIELD_LIMIT` 或构造参数受控调整；超大请求继续走现有字段分批与递归缩分逻辑。
6. 新增现有真实资料基线准备工具，所有实际数据集产物仍只写入 Git 忽略的 `workspace/runtime`。

## 失败原因与下一优先级

1. P0：为扫描 PDF 建立本地 OCR 路径，并验证跨页表格、复杂表头和 bbox 回映。
2. P0：为 Word 自由文本建立本地或获准的模型抽取路径，优先处理人口、受体和点位实体归属。
3. P0：增加芦溪台账映射；现有九江专用配置会确定性排除芦溪行。
4. P0：安排人工复核并记录每份资料耗时；AI 初标不能替代业务签字。
5. P1：补至少一组多文件同实体、旧版/新版冲突样本，否则冲突识别指标无法验收。
6. P1：补原始 CIPS 时序、检测维修闭环和气象联合概率资料。
