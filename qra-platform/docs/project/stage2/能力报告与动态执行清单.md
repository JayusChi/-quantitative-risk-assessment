# 九江真实试点能力报告与动态执行清单

## 1. 数据能力

阶段 1 快照提供 6 类显式数据类别、1 个 10.938 km 全线管段和 0 个计算人口单元。17 个指标组中，当前直接识别到“管道几何、材料与设计”和“运行工况与输送介质”2 组；管段外径、材质、设计压力及运行压力范围可追溯，但运行压力范围没有被擅自折算为单值。

能力报告共列出 22 条节点输入缺口。它们既包括具体字段，也包括完整人员 QRA 合同中的 `assessment`、`frequency_library`、`weather_joint_probability`、`population_cells` 和 `ignition_model` 数据段。数据类别数量仅用于盘点，不能替代字段合同。

## 3. 可得与不可得输出

当前可得：数据能力 JSON、指标覆盖 JSON/SVG、管段几何 JSON/SVG、自适应风险 JSON、PLL 排序/范围/证据因子 SVG、矩阵 JSON/CSV/SVG、沿线剖面 SVG、HTML 报告和 ZIP。

当前不可得：分机理失效频率、泄漏点、独立 AQ/T 3046 源项、喷射火阈值、GB/T 34346 附录 C 校核、完整人员 QRA、数值 IR 和项目 F-N。缺人口时不再生成 F-N 或融合 IR 图，避免以先验人口结果冒充项目人口结果。
