## 2. 业务解释

当前排序只有一个元素。“第 1 名”和“全线贡献 100%”只是单段集合的数学结果，不能定位全线哪一处风险更高，也不能与现场认知、第三方施工活动或完整性证据开展区段级一致性比较。

台账文字显示工业园、国道绿化带和第三方施工活动，但没有权威里程/坐标，不能定量关联到管段内部位置。完整性评价摘要说明 2021～2024 年开展过内腐蚀评价、防腐层检测修复、阴保有效性评价和 ECDA，但没有结构化测量值，证据更新模型 8 项响应均按缺失中性处理，证据因子为 1.0、不确定性因子为 10.0。因此当前异常排序不能解释为“真实低风险”，也不能据此确认现场认知一致。

## 3. 四层异常排查

| 层次 | 结论 | 处理 |
|---|---|---|
| 数据 | 空间分段、坐标、人口、温度、壁厚、阀门、气象等缺失 | 保持缺失，进入补数清单，不补 0 |
| 映射 | 未发现新增软件映射缺陷；压力范围 `3.0–3.8 MPa` 忠实保留 | 阶段 2 不擅自选择上界、均值或分布 |
| 参数 | 筛查使用 4.0 MPa、288.15 K、10 mm、默认人口密度及物性/点火先验 | 全部只用于内部能力筛查；阶段 3 建库、校准和批准 |
| 公式 | 本次 0 个节点运行失败，但关键物理模型尚未独立验证 | “运行成功”不等于模型验证通过，阶段 4 再作基准/收敛性 |

## 4. 结果分类

- `DATA_MISSING`：空间人口、坐标、工况、壁厚、阀门、气象等；
- `PARAMETER_NOT_APPROVED`：频率库、K_j、孔径比例、物性、点火和风险准则；
- `MODEL_NOT_VALIDATED`：证据更新系数、瞬态破裂、高压近场扩散、喷射火/TNO 和收敛性；
- `TRUE_LOW_RISK`：本次没有证据支持该分类；
- `SCREENING_ESTIMATE_ONLY`：PLL、PLL/km、上下界、主导场景和展示矩阵均属此类。
