# M1.5 完成定义

## 1. 完成判定

M1.5 只有在以下 18 项同时满足、正向和负向自动化验收均通过后才算完成。阶段 0 只冻结这些条件，不宣称它们已经实现。

| ID | 必须满足的条件 | 验收要点 |
|---|---|---|
| DoD-01 | 用户从页面创建或加载合成项目 | 普通用户入口，无需命令行 |
| DoD-02 | 系统接收多格式合成原始资料 | 覆盖约定的 XLSX、CSV、DOCX、PDF 和图片路径 |
| DoD-03 | 系统执行真实解析、OCR、提取、标准化和冲突处理 | 允许确定性回放，不允许绕过编排 |
| DoD-04 | 用户无需接触代码和 JSON | 页面可完成主流程和必要复核 |
| DoD-05 | 所有关键项目事实都有原始证据 | 可定位到单元格、页、段落或 bbox |
| DoD-06 | 所有系统参数都有版本化参数包来源 | 参数不得伪装成用户资料事实 |
| DoD-07 | 所有场景假设都有明确记录 | 记录决定人、原因、时间和版本 |
| DoD-08 | 服务端门禁通过后形成不可变快照 | 未解决阻断项时禁止确认 |
| DoD-09 | 快照与黄金答案一致 | 使用字段级规则比较，差异显式化 |
| DoD-10 | 自动完成 11/11 计算节点 | completed=11、skipped=0、failed=0 |
| DoD-11 | 结果与现有合成基线一致 | 当前五场景数值哈希作为基线 |
| DoD-12 | 自动生成图表和受控报告草稿 | 输出结构完整且可打开 |
| DoD-13 | 报告所有数字与计算结果一致 | 确定性引用与一致性校验通过 |
| DoD-14 | 报告明确标记全部数据为人工合成 | 页面、文件名、页眉/水印和声明一致 |
| DoD-15 | 正式报告门禁保持关闭 | `formal_report_allowed=false` |
| DoD-16 | 正向和负向端到端测试全部通过 | 至少覆盖计划中的 D00、D10、D20、D30、D40、D50 |
| DoD-17 | 新环境可以按手册重复启动和演示 | 安装、启动、运行和导出步骤可复现 |
| DoD-18 | 报告可反查结果、快照、复核决定和原始资料 | 反向追溯链完整且任务/版本隔离 |

## 2. 强制验收语义

- 第一条完整链固定为 `S00_BASELINE × D00_CLEAN`。
- 正式自动化验收以 `SYNTHETIC_DETERMINISTIC` 为必过模式；`SYNTHETIC_LIVE_MODEL` 单独验收，公网波动不得阻断确定性回归。
- 标准 JSON 是黄金答案，不是原始资料入口；直接导入标准 JSON 的路径不计为 M1.5 通过。
- 缺失、冲突、低置信度和文档提示注入必须按预期阻断或进入人工复核，不能静默放行。
- 所有数值计算、哈希、表格、图表和报告数字一致性检查必须由确定性程序完成。
- 任一场景出现 `formal_report_allowed=true`，M1.5 验收立即失败。
- 任何条件只有“存在代码”或“存在文档”而无对应运行证据时，仍视为未满足。
