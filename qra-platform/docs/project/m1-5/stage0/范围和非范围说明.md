# M1.5 范围和非范围说明

## 1. 唯一目标产品等级

M1.5 只交付 `DEMO_SYNTHETIC`：完全使用人工合成数据跑通资料理解、复核、不可变快照、11 节点计算、图表和受控测试报告。

所有演示输入、快照、结果和报告必须携带或可追溯到以下边界：

- `data_classification=SYNTHETIC_TEST_ONLY`；
- `zero_real_project_data=true`；
- `formal_report_allowed=false`；
- 合成数据包、参数包和生成器的版本及哈希；
- 允许用途和禁止用途。

允许用途限于软件开发、自动化回归、内部演示、培训和合成场景算法响应检查。禁止用于真实资产评价、工程设计决策、风险接受性结论、监管报送或正式签发。

## 2. 第一条验收链

第一条、也是阶段 1 至阶段 4 的优先验收链固定为：

```text
S00_BASELINE × D00_CLEAN
```

S00×D00 通过后才批量扩展 S10 至 S40 和 D10 至 D70。计算情景与资料质量情景必须保持两个独立维度。

## 3. 固定目标节点

目标节点总数固定为 11：

1. `data_inventory`
2. `indicator_coverage`
3. `segment_geometry`
4. `failure_frequency`
5. `leak_point_discretization`
6. `aqt3046_source_term`
7. `jet_fire_thresholds`
8. `gbt34346_annex_c`
9. `adaptive_evidence_qra`
10. `human_qra`
11. `risk_matrix`

目标集合变更属于范围变更，必须追加决策记录、说明对字段矩阵、快照、黄金结果和报告的影响，并重新执行相关阶段门。

## 4. 不可绕过的原始资料规则

M1.5 验收入口必须是多格式合成原始资料。`qra_synthetic_case_v1.json` 及其派生标准 JSON 只允许作为：

- 合成资料生成器的受控输入；
- 字段、快照和数值结果的黄金答案；
- 差异分析与回归判定基线。

下列路径不得计为 M1.5 端到端通过：

```text
直接上传标准 JSON → 快照或计算 → 报告
```

合格路径必须真实经过文件入口、安全检查、解析或 OCR、字段提取、标准化、实体对齐、冲突/缺失处理、人工复核、服务端门禁和不可变快照。确定性回放可以替代公网模型调用，但不得绕过业务编排和门禁。

## 5. 数据边界

输入必须分成三层并分别保留来源：

| 层 | 内容 | 来源要求 |
|---|---|---|
| `PROJECT_FACT` | 管段、工况、气质、检测、人口、气象等项目事实 | 多格式合成原始资料及证据位置 |
| `MODEL_PARAMETER` | 频率、孔径、后果、点火、风险准则等模型参数 | 版本化合成参数包，不得伪装成资料提取值 |
| `RUN_ASSUMPTION` | 场景、冲突选择、人工填写、用途和目标节点 | 运行配置或不可变快照中的可审计决定 |

## 6. 本项目非范围

- `REAL_SCREENING` 和 `FORMAL_QRA`；
- 真实项目风险结论或正式工程报告；
- 生产频率库、修正系数、风险准则或模型的自行批准；
- 使用大模型执行或改写任何数值计算；
- 把缺失字段自动填成 0；
- 用 0～100 综合分数替代正式 QRA；
- 任意行业、任意客户格式的通用识别；
- 微服务、分布式事务或复杂消息队列；
- 解除任何正式签发阻断。

## 7. 发布边界

阶段 0 至阶段 7 的任何中间产物均不得对外描述为正式 QRA。即使 11/11 节点完成、报告已生成，也必须保持：

```text
formal_report_allowed=false
```

如果该值为 `true`、字段缺失、或任何导出物缺少合成声明，验收必须失败。
