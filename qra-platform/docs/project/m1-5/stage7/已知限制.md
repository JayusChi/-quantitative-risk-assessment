# 已知限制

1. 本版本只随附全合成资料、参数和黄金结果，禁止用于真实资产评价、监管申报或安全决策。
2. `formal_report_allowed` 固定受控为 `false`；人工确认只能得到 `CONFIRMED_TEST_ONLY`。
3. 人员后果、近场扩散、瞬态破裂泄放、TNO 曲线数字化、生产热物性/点火/占用/拥塞参数、IR 网格和泄漏点收敛仍有正式验证或批准缺口。
4. 失效频率修正模型或项目系数未达到 `APPROVED_CALIBRATED`/`APPROVED_PROJECT_FACTORS` 生产状态。
5. D30/D40 使用合成的 OCR、低质量和超大图片测试夹具，未覆盖所有扫描仪、语言、手写体和真实 OCR 服务组合。
6. 在线模型实际调用边界已经接通并要求显式资料外发授权；2026-09-02 已对当时 69 个直接证据字段完成阿里云百炼真实验收。本次扩展后的 256 个直接证据字段只完成离线确定性验收，尚未重新外发做 256/256 在线精度验证；演示包也不内置外部大模型凭据。
7. 首次安装需要本机 Python 3.10+，并通常需要访问 Python 包索引。发布 ZIP 当前不包含离线 wheel 仓库。
8. 已加入 TLS/可信反向代理、非本机与生产模式失败关闭、管理令牌内存保存、CSP nonce、HSTS 和最小健康响应等安全基线；共享管理令牌仍不替代企业身份、RBAC 和密钥托管，多租户、集中监控与高可用仍未实现。
9. DOCX/PDF/HTML 已进行程序化内容与哈希验收；不同办公软件和打印驱动的视觉细节可能略有差异。
10. 备份恢复覆盖演示数据库的逻辑一致性；外部对象存储、跨主机灾备和长期法规归档不在当前范围。

机器可读的生产就绪门见 `resources/synthetic/full-chain-v1/stage7/production-readiness.json`；状态保持 `BLOCKED_EXTERNAL_GOVERNANCE_AND_ARCHITECTURE`。
