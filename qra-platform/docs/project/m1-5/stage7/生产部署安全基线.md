# 生产部署安全基线与未关闭门

截至 2026-09-02，服务已实现可验证的部署安全基线：生产或非本机监听缺少管理令牌、TLS 证书或明确的可信 TLS 反向代理时拒绝启动；可直接加载 TLS 证书/私钥；管理令牌仅保留在当前页面内存；HTML 使用 CSP nonce；HTTPS 响应包含 HSTS；健康接口不再返回数据库绝对路径。

这些控制是生产化基础，不构成生产认证。以下事项必须由部署组织提供架构与治理输入后才能关闭：

- 企业统一身份、角色权限、令牌轮换与集中密钥托管；
- 租户标识、全表数据隔离策略和跨租户渗透测试；
- 多实例任务协调、共享对象存储、监控告警、容量和高可用演练；
- 真实扫描件/OCR 组合验收、真实资产数据质量验收；
- 正式参数校准、模型验证、专家批准与报告签发责任链。

因此，当前允许发布的仍是 `DEMO_SYNTHETIC`。不得通过设置环境变量或打开 `formal_report_allowed` 绕过上述门。
