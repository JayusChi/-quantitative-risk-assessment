# 管理和审计手册

## 管理入口

- 普通用户入口：`/projects/`
- 高级管理与审计：`/admin/`
- 运行数据库：发布目录 `.runtime/workspace/state/qra.sqlite3`
- 运行产物：发布目录 `.runtime/workspace/runtime`

服务只默认监听 `127.0.0.1`。当前演示版不提供生产级身份认证、TLS 或多租户隔离，不应直接暴露到外部网络。

## 关键受控对象

| 对象 | 不可变或校验要点 |
|---|---|
| 原始资料与证据 | 保存来源、内容哈希、页/单元格/坐标定位 |
| 决策集 | 冲突解决后生成 `decision_set_sha256`，报告证据索引记录决策集 |
| 输入快照 | 确认后由数据库不可变保护；计算只读取该版本 |
| 计算结果 | 11 节点结果和总数值哈希可与黄金基线比对 |
| 报告上下文/草稿/产物 | 上下文、草稿、HTML、PDF 等均保存 SHA-256 |
| 人工确认 | 确认前重新校验上下文、草稿、产物、数值、引用和水印 |

## 重点审计事件

- `STAGE3_SNAPSHOT_CONFIRMED`：输入快照和人工决策集确认。
- 计算任务创建、状态推进、恢复与节点执行事件：用于证明 11 节点状态和重启恢复。
- 受控报告生成和确认事件：保存版本、哈希、提供器/降级模式和确认人。
- `CONTROLLED_REPORT_CONFIRMATION_REJECTED`：候选草稿或已存报告完整性失败，确认被拒绝。
- 提示注入、模型不可用、低置信度与 OCR/切片问题：保存在转换结果、复核工作包和验收证据中。

## 防篡改核查

报告确认会重新计算并比对上下文、草稿和产物哈希，再执行受控报告规则、渲染数值与水印检查。任何差异都会阻止确认并写入拒绝审计。不要通过数据库工具修改受控载荷；数据库触发器会拒绝对不可变对象的变更。

## 故障与恢复

若服务在计算中断开，重新运行 `Start-Demo.ps1`。启动流程会识别可恢复状态并继续，不会重写已确认快照、已完成节点结果或报告资源。恢复后核对项目 11/11、结果哈希和报告状态。

若数据库损坏或需要回退，按 `备份恢复说明.md` 使用受控命令恢复。恢复命令在切换前执行 SQLite `quick_check`、模式版本检查和哈希核对。

## 审计边界

所有项目数据均为 `SYNTHETIC_TEST_ONLY`。人工确认、备份恢复和管理员查看都不会改变 `formal_report_allowed=false`。当前审计能力用于演示和软件验证，不替代生产环境的访问控制、集中日志、密钥管理、签名时间戳或法规归档。
