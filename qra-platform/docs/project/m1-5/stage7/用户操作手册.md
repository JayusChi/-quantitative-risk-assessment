# 用户操作手册

## 1. 环境要求

- Windows PowerShell。
- Python 3.10 或更高版本。
- 首次安装时可访问配置的 Python 包索引；依赖见 `版本和依赖清单.md`。
- 本地端口 8766 可用，或在启动时指定其他端口。

## 2. 安装与启动

解压 `QRA全合成端到端演示版_v1.zip`，在解压目录打开 PowerShell：

```powershell
.\Install-Demo.ps1
.\Start-Demo.ps1 -OpenBrowser
```

默认地址为 `http://127.0.0.1:8766/projects/`。如 8766 被占用：

```powershell
.\Start-Demo.ps1 -Port 8877 -OpenBrowser
```

启动脚本会在发布目录的 `.runtime` 下创建隔离环境、数据库和运行产物，并幂等加载演示项目。再次启动不会创建重复项目，也不要求编辑数据库或 JSON。

停止服务：回到启动脚本所在终端，按 `Ctrl+C`。

## 3. 标准演示流程

1. 打开“所有项目”。若数据库为空，点击“加载全合成演示项目”。使用发布脚本启动时，项目通常已经自动加载。
2. 进入“全合成QRA演示项目”，先阅读黄色的全合成数据警示。
3. 核对项目资料为 10 份，数据完整度 100%，计算进度 11/11。
4. 在“报告中心”生成或查看受控报告。
5. 使用“在本页查看受控 HTML”阅读报告；也可导出 ZIP、PDF 和 DOCX。
6. 如需演示确认流程，点击“人工确认报告”，填写复核人和理由。
7. 确认后核对状态为 `CONFIRMED_TEST_ONLY`，并确认“正式报告许可：未开放”。

## 4. 报告状态说明

| 页面状态 | 含义 |
|---|---|
| DRAFT | 报告已生成，等待人工复核 |
| CONFIRMED_TEST_ONLY | 已确认测试报告内容，但没有正式发布许可 |
| 正式报告许可未开放 | 合成数据、模型验证或参数批准条件仍阻断正式用途 |

人工确认不会把合成测试报告变成正式报告。

## 5. 常见问题

安装失败时，确认 Python 版本和包索引网络；可再次运行 `Install-Demo.ps1 -ForceInstall`。端口冲突时更换 `-Port`。页面状态未刷新时点击“刷新状态”或重新加载页面。运行数据均在 `.runtime` 下，备份前不要直接复制正在使用的数据库，请使用 `Backup-Demo.ps1`。
