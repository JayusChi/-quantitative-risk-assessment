# 备份恢复说明

## 备份

在发布目录打开新的 PowerShell。服务可以保持运行，备份命令使用 SQLite 在线备份接口生成一致副本：

```powershell
.\Backup-Demo.ps1
```

默认输出到 `.runtime/backups/qra-demo-<时间>.sqlite3`，并生成同名 `.manifest.json`。清单包含 SHA-256、模式版本、表计数和 SQLite `quick_check` 结果。

指定路径：

```powershell
.\Backup-Demo.ps1 -Output "D:\QRA-Backups\qra-demo.sqlite3"
```

目标已存在时默认拒绝覆盖；确认要替换时显式加 `-Replace`。

## 恢复

先停止正在运行的服务，再执行：

```powershell
.\Restore-Demo.ps1 -Input ".\.runtime\backups\qra-demo-20260901-180000.sqlite3" -Replace
```

恢复流程先验证备份可打开、`quick_check` 通过且存在受支持的 `db_schema`，随后复制到临时文件、再次核验并原子替换目标数据库。源备份和恢复数据库的逻辑 SHA 与表计数会在命令输出中报告。

恢复完成后重新启动：

```powershell
.\Start-Demo.ps1 -OpenBrowser
```

核对项目、输入快照、11/11、报告版本和正式发布边界。启动脚本是幂等的，不会重复创建演示项目。

## 注意事项

- 不要把正在运行数据库旁的 `-wal` 或 `-shm` 文件当作独立备份。
- 不要用文件管理器直接覆盖运行中的数据库。
- 恢复会改变当前演示库状态；保留原库时应先执行备份。
- 当前脚本只管理演示数据库，不包含外部服务凭据或生产对象存储。
