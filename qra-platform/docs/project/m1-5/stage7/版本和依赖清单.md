# 版本和依赖清单

## 发布版本

- 发布名称：`QRA全合成端到端演示版_v1`
- Python 包：`pipeline-qra-platform 1.0.0`
- QRA 引擎：`qra-engine/0.6.1`
- 数据库适配器：`db-adapter/0.1.0`
- 最低 Python：3.10
- 数据库：SQLite，模式由应用迁移和 `db_schema` 表管理

## Python 运行依赖

| 依赖 | 约束 | 用途 |
|---|---|---|
| jsonschema | >=4.23,<5 | 结构与报告 Schema 校验 |
| openpyxl | >=3.1,<4 | XLSX 读取 |
| Pillow | >=11,<13 | 图片预处理与图表 |
| pdfplumber | >=0.11,<1 | PDF 内容与布局提取 |
| pypdf | >=5,<7 | PDF 结构处理 |
| python-docx | >=1.1,<2 | DOCX 读取与报告生成 |
| reportlab | >=4,<5 | PDF 报告生成 |
| xlrd | >=2.0,<3 | 旧版 Excel 读取 |

测试依赖：`pytest>=8,<9`。代码质量检查使用 Ruff。真实浏览器验收使用 headed Chromium 和 Playwright CLI 0.1.18。

## 已验证环境

- 操作系统：Windows，PowerShell。
- 浏览器视口：1440×900、390×844。
- 默认监听：`127.0.0.1:8766`。
- 发布内容哈希：发布目录的 `checksums.sha256`。
- 发布结构和文件清单：`release-manifest.json`。

安装脚本会在发布目录 `.runtime/venv` 创建独立虚拟环境，不修改用户的项目数据库。实际解析到的补丁版本以 `.runtime/venv` 中的 `pip freeze` 为准。
