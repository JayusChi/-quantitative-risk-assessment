# 发布清单

发布名称：`QRA全合成端到端演示版_v1`

## 根目录

- `Install-Demo.ps1`：创建隔离虚拟环境并安装运行依赖。
- `Start-Demo.ps1`：幂等加载演示项目并启动本地服务。
- `Backup-Demo.ps1`：生成经核验的 SQLite 备份与清单。
- `Restore-Demo.ps1`：核验并原子恢复数据库。
- `README.md`：最短启动说明和安全边界。
- `pyproject.toml`、`src/`：可安装的 1.0.0 应用源码。
- `release-manifest.json`：发布身份、版本和文件列表。
- `checksums.sha256`：发布文件 SHA-256。

## 随附内容

- `resources/synthetic/full-chain-v1/`：阶段 1～7 全合成原始资料、场景、参数、黄金结果和验收记录。
- `example-report/`：HTML、PDF、DOCX 和 ZIP 格式的受控测试报告示例。
- `docs/`：用户、管理员、演示、限制、依赖、备份恢复和验收文档。

## 发布前核对

```powershell
.\.venv\Scripts\python.exe tools\run_full_chain_stage7_acceptance.py
.\.venv\Scripts\python.exe tools\build_full_synthetic_demo_release.py
```

阶段 7 验收必须是 19/19 PASS；全量测试、Ruff、编译、架构边界和差异空白检查均必须通过。发布目录冷启动必须无需手工编辑数据库或 JSON，真实浏览器控制台错误必须为 0，且所有页面和报告继续显示全合成边界及正式报告许可未开放。
