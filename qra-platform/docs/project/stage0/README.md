## 1. 执行结论

1. 当前核心业务范围冻结为：陆上埋地天然气输送管道的人员生命风险量化。
2. 首个试点唯一确定为：**江西省天然气九江支线 GDBZYQ-JJ-1**。
3. 试点边界冻结为：JJ001（0+000）至 JJ041G（10+938），总长 10.938 km；相邻瑞昌支线不纳入本案例。
4. 当前 11 个内部管段是按无 GPS 现场资料变化点形成的试点分段，属于待核对的工作基线，不是测绘里程或已确认黄金输入。
5. 软件、模型规格、通用映射和测试已用 Git 提交与标签固化；真实业务资料未进入版本库。
6. 九江和芦溪候选草稿均只能运行 6/11 个动态节点，均不得用于正式风险接受性结论。
7. 阶段 1 只允许围绕九江支线单线资料开展盘点、专用映射和黄金 JSON 验收；不得把九江、芦溪或瑞昌资料合并成一个案例。
