1. 当前核心业务范围冻结为：陆上埋地天然气输送管道的人员生命风险量化。

6. 九江和芦溪候选草稿均只能运行 6/11 个动态节点，均不得用于正式风险接受性结论。
7. 阶段 1 只允许围绕九江支线单线资料开展盘点、专用映射和黄金 JSON 验收；不得把九江、芦溪或瑞昌资料合并成一个案例。
