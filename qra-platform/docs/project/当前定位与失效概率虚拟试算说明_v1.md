# 当前定位与失效概率虚拟试算说明 v1

## 1. 结论

当前工程应定位为“管道定量风险评价垂直智能体平台的可审计计算内核与应用原型”，不是已经完成的生产级全自动智能体产品。

- 第一部分已有多格式读取、字段映射、冲突复核、输入快照和审计骨架，但主要是确定性转换器；DOCX/PDF仍属于辅助提取，尚未形成由大模型、OCR/视觉模型、工具调用和人工门禁组成的完整资料理解智能体。
- 第二部分已经具备失效频率、孔径场景、泄漏点、事件树、后果、IR、F-N、PLL、风险矩阵展示和动态节点编排，失效概率换算也已接通；但正式工程验证、批准参数库和真实项目数据尚不完整，所以只能说“功能链已形成，生产级定量评价尚未完成”。
- 第三部分已有结构化JSON、CSV、SVG、HTML和ZIP结果输出，但主要是模板化确定性报告；尚未形成基于受控结果快照、可追溯引用和人工签发的大模型报告智能体。

## 2. 风险定量评价全过程

风险不是一个脱离概率和后果的主观总分。人员域QRA的主链为：

```text
评价边界与基准日
→ 数据收集、证据定位和质量分级
→ 动态分段
→ 分失效机理、分孔径的年失效频率 λ
→ 泄漏源项、扩散、立即/延迟点火和事故类型
→ 热辐射、可燃云团、超压和人员死亡概率
→ IR、F-N、PLL及管段贡献
→ 风险准则、ALARP和措施后复算
→ 报告、评审、整改、验收和再评价
```

频率与概率必须分开：年失效频率 `λ` 的单位是 `1/年`，允许相加；在恒定Poisson强度假设下，`t` 年内至少发生一次失效的概率为 `P(N≥1)=1-exp(-λt)`，概率不能直接相加。后果是事故发生条件下的影响，风险才是场景频率与条件后果的聚合。

## 3. 第二部分的准确完成度

### 已经跑通

- SY/T 6891.2框架下的分机理基准频率、管段长度、项目化修正系数和孔径比例计算；
- 小孔、中孔、大孔、完全破裂频率守恒；
- 频率到指定年限内至少一次失效概率的Poisson换算；
- 泄漏点离散、事件树、AQ/T 3046后果公式链、IR、F-N、PLL和排序；
- 缺数据时按动态DAG跳过节点并形成补数清单；
- 合成案例、单元测试、集成测试和重复运行数值哈希。

### 仍不能宣称正式完成

- 缺经批准的项目失效频率库、分机理孔径比例和K_j校准；
- 缺瞬态完全破裂泄放与管存衰减、高压近场扩散、TNO曲线和生产参数库的完整独立验证；
- 缺真实GIS中心线、阀门/隔离、逐段壁厚、SCADA工况、气质、气象、受体坐标和人口时序；
- 缺IR网格/泄漏点收敛、独立软件或外部案例盲算、真实工程人工复核；
- 风险准则和正式签发边界仍需业主/专家书面批准。

因此，第二部分的正确表述是：**失效频率/概率模块并非没有做，算法和测试接口已经存在；本次又用两条支线的虚拟现场数据完成了专项联调。但第二部分尚未达到可直接签发正式QRA报告的工程完成状态。**

## 4. 本次虚拟现场数据

虚拟字段取自投标技术方案第11章、附录I.3和附录J的待填/结构化栏目，覆盖：

- 管段、起终里程和长度；
- 外防腐层缺陷密度、断电电位、土壤电阻率；
- 游离水概率、内腐蚀速率；
- 裂纹和未修复临界异常；
- 焊口返修率；
- 开挖活动密度、埋深、巡线周期；
- 滑坡易发性、冲刷深度；
- 规程执行率、误操作事件；
- 分机理基准频率、孔径条件分布和K_j模型。

所有虚拟值均标记为 `SYNTHETIC_TEST_ONLY`、质量等级D、`SYNTHETIC_NOT_FIELD_VERIFIED`，并触发正式报告阻断。

## 6. 建议实施顺序

1. 先冻结第二部分的工程数据合同和模型批准机制，补齐真实现场数据、频率库、K_j、物理模型V&V和风险准则。
2. 在稳定计算合同上建设第一部分资料理解智能体：OCR/版面解析、文档/表格/图像抽取、实体对齐、证据定位、置信度和人工双核。
3. 建设第三部分报告智能体：只读取冻结结果快照，生成图表解释、结论草稿、措施前后对比和引用检查，禁止改数、删场景或自行判定可接受性。
4. 最后打通“一键上传—待复核—冻结快照—计算—报告—签发”的无代码产品流程，并增加身份权限、任务队列、监控和企业部署能力。

## 7. 复现命令

在项目目录执行：

```powershell
.\.venv\Scripts\python.exe .\tools\run_jiangxi_failure_probability_demo.py
```

脚本会生成两份虚拟输入、两套动态节点输出、汇总CSV、虚拟字段CSV和试算总览JSON。再次运行会以相同规则生成相同数值结果哈希。
