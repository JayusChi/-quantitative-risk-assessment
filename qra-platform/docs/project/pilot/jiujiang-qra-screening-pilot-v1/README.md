> 试点 ID：`jiujiang-qra-screening-pilot-v1`<br>
> 定义版本：`1.0.0`<br>
> 当前结论：`PILOT_READY_FOR_IMPLEMENTATION`
> 适用范围：仅限内部第一阶段测试，不代表正式发布、正式 QRA 或监管报告批准

## 负责人摘要

本试点选择九江天然气支线 `GDBZYQ-JJ-1`。仓库已有客户专用映射 `jiangxi-natural-gas.jiujiang.v1`、真实资料转换记录和证据条件化筛查运行记录，可在不修改计算公式、不制造缺失数据的前提下建立第一条“资料—字段—计算节点—报告结果”合同。

权威管段范围只采用高后果区台账能够直接证明的 1 个管段：起点 0.000 km、终点 10.938 km、长度 10.938 km。现场照片和自由文本没有权威里程、测绘坐标或 GPS 证据，不能生成 11 个内部计算管段，也不能凑成 10～20 个管段。

## 第一版支持的资料

1. 管段/高后果区台账：确定性表格映射，形成管线和单段边界候选；
2. 运行工况表：预期确定性提取压力、压力基准、温度和气体组分；当前缺失；
3. CIPS 检测表：预期确定性提取通电/断电电位及超限比例；当前缺失；
4. 缺陷与维修台账：预期确定性提取异常计数、尺寸、临界缺陷和维修完成情况；当前缺失；
5. 人口与受体资料：需要人工空间复核，扫描件可作为证据；当前缺失；
6. 项目范围 PDF/DOCX：只用于范围治理，不作为工程参数权威来源；
7. 标准参考 PDF：只用于专家批准参数和边界解释，不作为项目事实或默认值来源。

## 明确不做

- 不生成完整空间人员域 QRA、IR、项目 F-N 或正式 PLL 结论；
- 不作正式风险接受性判定、监管报告或工程签章；
- 不要求 `failure_frequency`、`leak_point_discretization`、`aqt3046_source_term`、`jet_fire_thresholds`、`gbt34346_annex_c`、`human_qra` 成为第一版成功门槛；
- 不修改公式、通用映射、既有黄金结果或测试 fixture；
- 不将压力范围折成单值，不把缺失值写成 0，不使用合成测试默认值；
- 不根据照片、文字描述或文件名推断坐标、里程、管段或人口单元；
- 不调用真实云端 OCR/大模型，不允许真实资料外发。

## 是否具备开工条件

当前具备第一阶段定义包实施和内部联调的开工条件。用户已代表项目领导批准 6 份资料用于内部测试、批准采用 1 个权威管段，并同意以三个相互区分的虚拟测试角色承担本阶段签批责任。6 份文件已放入 `workspace/pilots/jiujiang-qra-screening-pilot-v1/sources/`，机器校验为 `validation_status=PASS`、`status=READY`，开放 P0 为 0。

该结论只关闭第一阶段定义和内部测试的前置条件。当前尚未执行“解析—候选—复核—不可变快照—动态计算—报告”完整链路，不能把此前内部运行产物当作本试点经受控资料确认形成的输入快照，也不能声称筛查报告已经生成。

## 主要风险

- 只有 1 个权威管段，筛查排序不具有区段比较意义；
- 41 个字段缺失或待批准，证据覆盖率低，风险不确定性带会较宽；
- 人口空间数据缺失，无法计算完整人员域风险；
- 压力基准、CIPS 日期、逐缺陷维修状态等业务概念在 v1 字段字典中没有专用 `field_id`，必须走合同评审，不能在试点文件中自行造字段。
