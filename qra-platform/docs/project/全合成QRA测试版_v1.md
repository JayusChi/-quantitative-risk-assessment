# 全合成 QRA 测试版 v1

## 1. 定位

本测试版在完全没有真实项目数据的前提下，验证定量风险评价第二部分的工程链路。输入中的管线、管段、现场指标、失效频率、孔径比例、修正因子、人口、气象、气质、点火概率和物理参数均为人工合成数据。

测试版可以用于软件开发、算法联调、回归测试、培训演示和后续真实数据接入准备；不得用于真实资产评价、正式 QRA 报告、监管报送或安全决策。

## 2. 合成数据包

基准场景包含：

- 1 条 8 km 埋地天然气管线，设计压力 10 MPa、运行压力 8 MPa；
- 20 个计算管段，覆盖农村、村庄、学校、工业和地质灾害等虚拟环境；
- 7 类失效机理、4 类泄漏孔径和每个管段对应的合成修正因子 `K_j`；
- 8 个人口网格，含昼夜人口和占用信息；
- 8 个气象联合概率组合，覆盖 D/F 稳定度、昼夜和四个风向；
- 合成气质、运行工况、点火参数、探测时间和关阀时间；
- 工程指标目录及按全局、管段类型和指定管段组织的合成现场观测。

所有场景输入均带有 `SYNTHETIC_TEST_ONLY`、`zero_real_project_data=true` 和禁止正式使用的元数据。生成过程不使用随机数，同一版本输入可重复生成。

## 3. 场景设计

| 场景 | 人工改变的参数 | 预期响应 |
| --- | --- | --- |
| S00 基准 | 不扰动基准合成参数 | 作为比较基线 |
| S10 腐蚀恶化 | 提高指定管段外腐蚀、内腐蚀和应力腐蚀修正因子 | 失效频率和 PLL 上升 |
| S20 第三方活动激增 | 提高村庄、学校和工业段第三方损伤因子及开挖活动测试值 | 失效频率和 PLL 上升 |
| S30 高压力与人口峰值 | 运行压力提高到 9.5 MPa，昼夜人口提高 50% | 后果、PLL 和最大 IR 上升 |
| S40 综合治理 | 降低腐蚀、第三方、地灾和误操作因子，并缩短探测、关阀时间 | 失效频率和 PLL 下降 |

## 4. 计算链路

每个场景均执行完整的 11 节点动态流程：

1. 数据清单；
2. 工程指标覆盖率；
3. 管段几何；
4. 失效频率与泊松失效概率；
5. 泄漏点离散；
6. AQT 3046 源项；
7. 喷射火热辐射阈值；
8. GB/T 34346 附录 C；
9. 自适应证据 QRA；
10. 人员 QRA（IR、F-N、PLL）；
11. 风险矩阵。

生成器还自动校验：5 个场景均为 `PASS`、11 个节点全部完成、没有跳过或隔离失败节点、场景变化方向符合预期，并且正式报告闸门始终关闭。

## 5. 运行和产物

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe .\tools\run_synthetic_test_edition.py
```

默认输出目录为 `workspace/outputs/QRA全合成测试版_v1`：

- `index.html`：五场景总览和场景报告入口；
- `inputs/`：可重复导入的五份完整合成输入；
- `scenarios/`：每个场景的节点 JSON、图表、矩阵和 HTML 报告；
- `scenario-comparison.csv/json`：场景对比指标；
- `scenario-response-checks.json`：场景响应及发布闸门检查；
- `edition-summary.json`：版本状态及各场景数值结果哈希。

使用 `--no-charts` 可以在回归复算时跳过图表生成。

## 6. 工程边界与真实数据替换

这版证明的是“输入—频率—后果—风险—报告”的软件链路可以跑通，不证明计算结果适用于任何真实管线。正式化之前仍需：

- 用现场采集或审查后的真实字段替换合成观测；
- 经项目批准的基准频率库、孔径比例和 `K_j` 替换测试参数；
- 完成瞬态破裂/管存衰减和近场扩散的基准校核；
- 用独立软件或公开外部案例交叉验证；
- 完成 IR 网格、泄漏点收敛性及风险准则审批。

真实数据接入时应保留当前合成包作为回归基线，而不是覆盖或改写它。
