## 2. 与既有 11 段筛查草稿的差异

| 项目 | 既有筛查草稿 | 阶段 1 黄金候选 | 处理理由 |
|---|---|---|---|
| 管段数量 | 11 | 1 | 只有全线起终点和总长有权威台账证据 |
| 内部分段里程 | 按照片数量比例分配 | 不生成 | 照片无 GPS、拍摄时间和等距离证据 |
| 坐标 | 沿 x 轴构造的筛查坐标 | 不生成 | 无测绘或 GIS 数据 |
| 计算人口单元 | 11 | 0 | 人口位置、昼夜、室内外比例不完整；不制造计算事实 |
| 台账总人口/目标 | 拆分为代理人口 | 保留在高后果区原始描述 | 汇总文字不能确定性拆分到点位和时段 |
| 运行压力 | 取范围上界 3.8 MPa | 保留 `3.0-3.8` 字符串 | 数据转换阶段不得擅选筛查压力 |
| DOCX 目标说明 | 人工映射到 11 段 | 审核后不导入计算单元 | 没有唯一里程或坐标，转人工补数 |
| 正式 QRA | `false` | `false` | 数据、参数和模型发布条件均未满足 |

## 4. 脱敏黄金回归

版本库只保存脱敏源表和脱敏期望 JSON。回归案例保留多管线同表、两层表头、`273mm`、压力范围、0+000/10+938 里程和其他支线过滤特征，去除负责人、真实地区、详细目标描述和原始媒体。测试验证：

1. 一张源表可受控映射到多个业务层级；
2. 只允许 `GDBZYQ-JJ-1` 进入案例；
3. 单位后缀和米到公里换算确定；
4. 运行压力范围不被折算为单值；
5. 输出与脱敏黄金业务 JSON 一致；
6. 重复转换哈希稳定。
