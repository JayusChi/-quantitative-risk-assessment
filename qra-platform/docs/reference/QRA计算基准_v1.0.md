# 天然气输送管道 QRA 计算基准 v1.0

版本日期：2026-08-04  
模型标识：`QRA.NG.PIPELINE.MULTI_CONSEQUENCE.v1`  
状态：计算层首版基准  
资料状态：AQ/T 3046—2013 正文已取得；后果模型条款待规格化与技术复核

## 1. 结论

首版算法确定为：**陆上埋地高压天然气输送管道多后果域 QRA**。

它不使用风险指标打分、主观权重或 5×5 风险矩阵作为计算核心，而是逐级计算：

```text
区段失效频率
  × 泄漏孔径比例
  × 天气/风向概率
  × 点火及事故后果分支概率
  × 各后果域的损害函数
= 人员风险 + 财产风险 + 环境风险 + 供气连续性风险
```

四类风险共享同一套失效频率、泄漏、扩散和火灾爆炸场景，但分别使用自己的后果函数、单位、接受准则和区段榜单。平台不设置“人员风险为全局默认”，也不把四类结果用任意权重合成一个总分。

多个标准不合并成一个加权公式。它们按职责组成一条计算链：

| 层级 | 采用文件 | 在算法中的职责 |
|---|---|---|
| QRA 主标准 | SY/T 6891.2—2020 | 场景、孔径、频率方法、事件树、IR、F-N、ALARP、报告 |
| 管道评价导则 | SY/T 6859—2020 | 数据、风险因素、分段、方法选择、不确定性、再评价 |
| 通用风险技术 | GB/T 27921—2023 | 模型开发、验证、敏感性、记录与决策质量控制 |
| 后果与伤害模型引用 | AQ/T 3046—2013 | 按 SY/T 6891.2 的明确引用，提供泄漏、扩散、火灾爆炸、暴露影响和人员伤害计算依据；其自身范围排除长输管道，因此不作为管道 QRA 主标准，也不直接套用其设备失效频率和企业风险准则 |
| RBI 后果补充 | GB/T 26610.5—2022 | 泄漏、燃烧爆炸和后果面积模型插件，用于适用场景的补充计算与交叉校核 |
| 外部校核工具 | DNV Phast/Safeti 8.4 | 可选的独立对比工具或外部插件，不定义平台算法，也不是正式计算的默认依赖 |

评分型、半定量标准不进入本模型的频率或风险计算；可以复用其原始数据字段和风险因素分类，但不能复用分值、权重或风险等级。

## 2. 适用边界

### 2.1 本版适用

- 陆上、埋地、钢质天然气输送管道；
- 运行期管道；
- 高后果区，包括人口、环境、重要设施和供气保障等不同类型的高后果区；
- 支持人员、财产、环境、供气连续性四个后果域按项目目的启用；
- 输出各后果域的绝对量、区段贡献、接受性判断及措施前后残余风险。

### 2.2 本版不直接适用

- 城镇低压/中压配气管网和 PE 管；
- 站场内部工艺装置；
- 海底管道；
- 原油、成品油、液化天然气或两相流管道；
- 含硫天然气的毒性风险，除非另行接入毒性扩散和剂量模型；
- 生态价值或间接经济损失的货币化，除非项目另行批准价值模型。

超出边界时必须选择新的模型包，不能仅修改几个权重继续计算。

## 3. 标准整合规则

### 3.1 主从关系

1. 先用资产类型和评价目的确定主标准。
2. 主标准定义计算对象、场景、风险度量和输出。
3. 导则补充流程、数据和质量控制。
4. 规范性引用补充主标准明确调用的物理模型或伤害模型。
5. 软件只负责执行模型，软件默认值不能自动取代标准要求。

### 3.2 冲突处理

- **同一问题规定不同**：按适用性更具体的标准执行；同级仍冲突时建立两个模型版本，禁止平均。
- **主标准允许多种频率方法**：一次运行中，每个失效机理只分配一种方法，禁止重复相加。
- **标准未给参数值**：由经过批准、版本化的参数库提供，并记录来源、适用地区、时间窗和不确定性。
- **标准未给风险接受数值**：算法照常输出 IR 和 F-N，但不得自动声明“可接受”或“不可接受”。
- **半定量标准给出权重**：权重仅属于其原模型，不能进入 QRA。

## 4. 计算索引与最小数据单位

主要索引如下：

| 索引 | 含义 |
|---|---|
| `s` | 工程区段 |
| `p` | 区段内计算泄漏点 |
| `k` | 失效机理 |
| `l` | 泄漏孔径类别 |
| `m` | 天气类别 |
| `φ` | 风向类别 |
| `τ` | 昼夜/人口时段 |
| `b` | 事件树后果分支 |
| `c` | 人口栅格单元 |

必须区分两个空间单位：

- **工程区段**：属性一致、用于频率计算和治理责任划分；
- **计算泄漏点**：用于后果场和风险积分，初始间距 50 m，继续加密直至风险曲线收敛。

## 5. 完整算法

### 5.1 步骤 A：适用性检查和数据冻结

一次运行首先冻结：评价时点、管线几何、区段属性、工况、天然气组分、阀室、天气玫瑰、人口栅格、频率库、模型参数、软件版本、风险接受准则和随机种子。

任何阻断项缺失时不出正式风险结论。阻断项见第 9 章。

### 5.2 步骤 B：工程区段划分

遇到下列属性变化点必须切段：

- 外径、壁厚、钢级、设计压力或运行压力；
- 投产时间、防腐层、阴极保护状态；
- 阀室和可隔离边界；
- 地区等级、人口或重要受体明显变化；
- 埋深、穿跨越、地形地貌或地质灾害区；
- 内检测覆盖、缺陷类型或检测日期；
- 第三方活动强度、施工历史或管理责任边界。

相邻区段只有在所有关键属性和频率修正模型输入一致时才可合并。每个边界保存 `split_reason`。

### 5.3 步骤 C：失效场景

天然气管道采用四类泄漏场景：

| 类别 `l` | 等效孔径范围 | 代表孔径 |
|---|---:|---:|
| 小孔 | `0 < d ≤ 5 mm` | 5 mm |
| 中孔 | `5 < d ≤ 50 mm` | 25 mm |
| 大孔 | `50 < d ≤ 150 mm` | 100 mm |
| 破裂 | `d > 150 mm` | 管道内径/标准要求的全断面破裂 |

若管径小于 150 mm，只保留小于管径的孔径场景和完全破裂。

失效机理至少包括：外腐蚀、内腐蚀、应力腐蚀开裂、制造/施工缺陷、第三方损坏、自然与地质灾害、误操作。

### 5.4 步骤 D：失效频率

首版生产算法选择**历史失效数据修正法**作为默认方法，因为它适用于运行期管道，且最容易形成可审计、可校准的工程实现。

对区段 `s`、机理 `k`、孔径 `l`：

```math
\lambda_{s,k,l}=\lambda^0_k \times L_s \times q_{k,l} \times K_k(\mathbf{x}_s)
```

其中：

- `λ⁰_k`：机理 `k` 的基准失效频率，单位 `次/(km·a)`；
- `L_s`：区段长度，单位 km；
- `q_k,l`：该机理落入孔径类别 `l` 的比例，且 `Σ_l q_k,l = 1`；
- `K_k(x_s)`：区段证据对基准频率的修正函数；
- `λ_s,k,l`：区段年度失效频率，单位 `次/a`。

区段孔径场景总频率：

```math
\lambda_{s,l}=\sum_k \lambda_{s,k,l}
```

实现约束：

- 企业自身泄漏统计优先，其次才是经适用性验证的行业数据库；
- `K_k` 必须作为一个经过校准的多变量函数保存；不能未经验证地把多个相关修正因子连续相乘；
- 每个 `k` 在一次运行中只能使用历史法、结构可靠性法或故障树法之一；
- 结构可靠性法作为腐蚀、裂纹和已知缺陷的增强模型，在有检测数据、载荷和极限状态函数时启用；
- 故障树只用于有明确基本事件和可靠性数据的控制/误操作链，不使用标准附录中的示例值作为生产参数。

主标准附录 A 的一般形式为基准频率、孔径比例和修正函数的组合；平台公式在其基础上显式加入区段长度和索引。

### 5.5 步骤 E：泄漏点离散与频率分配

每个工程区段按 50 m 初始间距布置泄漏点。区段年度频率按相邻影响长度分配到泄漏点：

```math
\lambda_{p,l}=\lambda_{s,l}\times \frac{\Delta L_p}{L_s}
```

计算后将间距减半，比较所有已启用后果域的关键结果。满足以下全部条件才视为收敛：

- 最大 IR 相对变化不超过 5%；
- PLL 相对变化不超过 5%；
- 关键 IR 等值线到管道的最大距离变化不超过 10 m 或 5%，取较大者。
- 财产年期望损失、环境关键指标和供气中断关键指标的相对变化分别不超过 5%。

这是平台的数值收敛准则；项目可设置更严格阈值。

### 5.6 步骤 F：泄漏源项与隔离过程

对每个 `p,l` 计算随时间变化的泄漏率和累计泄漏量：

```math
M(t)=\int_0^t \dot m(u)\,du, \qquad M(t)\le M_{inventory}
```

源项应考虑：天然气组分、温度、压力、孔口形状、管径、孔径、上下游补气、阀室距离、检测时间、关阀时间、放空和管存量。

首版由平台内部计算模块执行源项、扩散、喷射火、闪火和蒸气云爆炸模型。每个模型必须先形成包含标准条款、公式、参数、单位、适用条件和验证案例的版本化 `model_spec`，再进入代码实现。平台把同一物理后果场分别送入人员、财产、环境和供气连续性适配器。

Phast/Safeti 只作为可选外部插件或独立交叉校核工具，不是平台模型依据，也不是正式运行的默认依赖。使用外部软件校核时，应保存软件版本、模型选项、输入文件哈希、结果文件哈希及差异说明；外部软件默认值不得覆盖平台已冻结的模型参数。

### 5.7 步骤 G：天气与风向

天气类别 `m` 至少由风速和 Pasquill 稳定度组成；风向 `φ` 单独离散。昼夜/人口时段记为 `τ`。优先从同一代表性数据集生成联合概率：

```math
\sum_m\sum_\phi\sum_\tau P_{m,\phi,\tau}=1
```

只有在有证据表明气象和时段可以独立处理时，才分解为：

```math
P_{m,\phi,\tau}=P_{m,\phi}\times P_\tau
```

此时分别校验 `ΣP_m,φ=1` 和 `ΣP_τ=1`。不能同时使用已经包含昼夜权重的天气概率和额外昼夜权重，以免重复计数。

### 5.8 步骤 H：点火事件树

天然气事件树固定为：

```text
泄漏
├─ 立即点火 → 喷射火
└─ 未立即点火
   ├─ 延迟点火
   │  ├─ 满足拥塞/受限条件 → 蒸气云爆炸
   │  └─ 不满足 → 闪火
   └─ 未点火 → 安全扩散
```

立即点火概率采用主标准附录 E：

| 泄漏率 | 低活动区 | 中/高活动区 |
|---:|---:|---:|
| `< 10 kg/s` | 0.02 | 0.20 |
| `10–100 kg/s` | 0.04 | 0.50 |
| `> 100 kg/s` | 0.09 | 0.70 |

延迟点火概率按点源、线源、面源和人口活动的空间叠加计算。单个持续着火源在 `0～t` 内的点火概率采用：

```math
P(t)=P_{present}\left(1-e^{-\omega t}\right)
```

多个独立着火源的合并概率使用补事件：

```math
P_{delayed}=1-\prod_j(1-P_j)
```

若存在相关或共因着火源，必须先聚类，不能直接按独立事件相乘。

事件树条件概率为：

```math
P_{jet}=P_{imm}
```

```math
P_{VCE}=(1-P_{imm})P_{delayed}P_{VCE\mid delayed}
```

```math
P_{flash}=(1-P_{imm})P_{delayed}(1-P_{VCE\mid delayed})
```

```math
P_{safe}=(1-P_{imm})(1-P_{delayed})
```

并强制校验四个分支之和为 1。只有在存在足够拥塞或部分受限空间、且可燃云满足模型适用条件时，才允许 `P_VCE|delayed > 0`。

### 5.9 步骤 I：物理后果场与多后果域映射

各事故分支输出空间伤害场：

- 喷射火：热辐射强度及暴露时间；
- 闪火：可燃云范围；
- 蒸气云爆炸：超压和冲量；
- 未点火扩散：可燃气体浓度、持续时间和释放总量；
- 若将来接入含硫气：增加毒性剂量场。

物理后果场只计算一次，随后映射到四个互不混合的后果域：

| 后果域 | 场景后果量 | 聚合风险量 |
|---|---|---|
| 人员 | 死亡概率、潜在死亡人数 | IR、F-N、PLL |
| 财产 | 设备/建筑损坏概率、维修与重置费用 | 年期望财产损失 `EAL_asset`，单位 CNY/a |
| 环境 | 释放质量、影响面积、敏感受体、恢复时间 | `E_release`、`E_area`、`E_recovery`，分别保留 kg/a、m²/a、day/a |
| 供气连续性 | 隔离范围、停输时间、未供气量、受影响用户 | `E_unserved_volume`、`E_customer_hours`，单位 m³/a、户·h/a |

对每个栅格中心 `x_c` 计算人员死亡概率：

```math
p^D_{p,l,m,\phi,\tau,b,c}
=f_{damage}(radiation, duration, overpressure, impulse, shelter)
```

人员域正式模型采用平台内部实现并验证的 AQ/T 3046 对应暴露与死亡概率模型。由于 AQ/T 3046 自身范围排除长输管道，本基准只在 SY/T 6891.2 明确调用的后果计算范围内引用其模型，不套用其化工企业设备频率、评价单元选择或风险准则。若采用其他等效模型，必须单独批准、版本化并标明符合性边界。

GB/T 26610.5—2022 可作为泄漏、火灾爆炸和后果面积模型插件及交叉校核，但其后果面积不能直接等同为管道沿线任意位置的死亡概率。SY/T 6891.2 附录 G 的热辐射和超压表用于结果合理性校核，不用离散阈值替代完整概率函数。Phast/Safeti 结果只能用于对比，不能代替上述模型依据。

财产、环境和供气连续性模型分别保存为独立的 `consequence_domain_model`。没有获批货币化依据时，环境风险不得折算为人民币；没有获批多准则决策规则时，不得把四个后果域合成一个分数。

### 5.10 步骤 J：分支频率

完整场景分支的年度频率为：

```math
f_e=\lambda_{p,l}\times P_{m,\phi,\tau}\times P_b
```

其中 `e=(p,l,m,φ,τ,b)`，`P_b` 为事件树条件分支概率。在气象与时段独立并有证据支持时，联合概率才可写为 `P_m,φ × P_τ`。

对人员风险，只有同时满足下列两个条件的场景才可按 SY/T 6891.2 筛除：

- 场景频率 `< 10⁻⁸ /a`；
- 最大人员死亡概率 `< 1%`。

对于多后果域运行，只有当场景同时满足人员筛除条件，并低于财产、环境和供气连续性三个已启用域的项目筛除阈值时，才能从全局场景集中删除；否则只允许从人员风险子计算中筛除。筛除前后总频率、各域风险量差值和场景清单必须保留在审计记录中。

### 5.11 步骤 K：个人风险 IR

个人风险是在某位置假定人员全年无防护暴露时的年死亡频率，因此不乘居民在家率或实际占用率：

```math
IR(x)=\sum_e f_e\times p^D_e(x)
```

参考高度为地面以上 1 m。输出包括栅格、最大值及指定阈值的等风险线。

为追踪区段贡献，同时保存：

```math
IR_s(x)=\sum_{e\in s} f_e\times p^D_e(x)
```

### 5.12 步骤 L：社会风险 F-N

场景 `e` 的潜在死亡人数：

```math
N_e=\sum_c Population_{c,\tau}\times p^D_{e,c}
```

人口数据必须区分昼夜或其他时段；如 `Population_c,τ` 已是该时段实际人口，则不能再次乘占用率。

对任意死亡人数阈值 `N`：

```math
F(N)=\sum_{e:N_e\ge N}f_e
```

输出阶梯型 F-N 曲线，并与项目批准的社会风险准则线比较。

### 5.13 步骤 M：多后果域风险聚合

人员风险继续计算年期望死亡人数：

```math
PLL_s=\sum_{e\in s}f_eN_e
```

财产风险计算年期望财产损失：

```math
EAL^{asset}_s=\sum_{e\in s}f_eL^{asset}_e
```

其中 `L_asset_e` 是场景直接损坏、维修、更换和经批准的直接停产损失，单位 CNY。间接声誉损失等不得在没有批准模型时混入。

环境风险保留可审计的物理量：

```math
E^{release}_s=\sum_{e\in s}f_eM^{release}_e
```

```math
E^{area}_s=\sum_{e\in s}f_eA^{environment}_e
```

```math
E^{recovery}_s=\sum_{e\in s}f_eT^{recovery}_e
```

对应单位分别为 kg/a、m²/a 和 day/a。生态敏感区命中、饮用水源命中等采用强制标志，不通过主观权重隐藏。

供气连续性风险计算：

```math
E^{unserved}_s=\sum_{e\in s}f_eV^{unserved}_e
```

```math
E^{customer\_hours}_s=\sum_{e\in s}f_eH^{customer}_e
```

对应单位为 m³/a 和户·h/a。四类结果按区段求和得到全线结果，但不同单位之间不得直接相加。

### 5.14 步骤 N：区段排序与治理优先级

平台不再定义一个全局默认的“最高风险 3 段”。每次查询必须指定 `ranking_basis`：

- `human_pll`：按 `PLL_s` 排序；
- `asset_eal`：按 `EAL_asset_s` 排序；
- `environment_release`、`environment_area` 或 `environment_recovery`；
- `service_unserved_volume` 或 `service_customer_hours`。

每个榜单同时展示主导失效机理、孔径、事故分支、占全线比例和 P5/P50/P95。任何后果域超过批准准则，或命中饮用水源、学校、医院、关键用户等强制条件的区段，都进入 `mandatory_action_segments`，不受榜单名次限制。

如果管理层需要跨后果域综合优先级，默认使用“强制约束 + Pareto 前沿”：先纳入所有超限/强制区段，再识别在四类风险量上不被其他区段全面优于的区段。只有项目批准了多准则决策模型、归一方法和权重时，才额外生成 `decision_priority_score`；该分数属于治理决策层，不属于 QRA 风险值。

### 5.15 步骤 O：风险判定

每个后果域使用独立、版本化的 `criteria_set`。风险判定可分为三类：

- 超过上限：不可接受，必须降低风险；
- 上下限之间：ALARP，进行措施论证并尽可能合理降低；
- 低于下限：可接受，但仍维持已有控制。

SY/T 6891.2 没有给出适用于所有管道项目的统一数值。平台分别设置 `human_criteria_set`、`asset_criteria_set`、`environment_criteria_set` 和 `service_criteria_set`。某域未配置准则时，该域状态只能是 `CALCULATED_NOT_JUDGED`；其他已配置域仍可独立判定。

### 5.16 步骤 P：不确定性与敏感性

正式 QRA 对以下参数定义分布或情景：

- 基准失效频率和修正函数；
- 孔径比例；
- 气象概率；
- 点火概率；
- 检测/关阀时间；
- 人口和占用；
- 维修/重置费用；
- 环境敏感受体、影响范围和恢复时间；
- 供气网络切换、停输时间、用户数和需求量；
- 后果模型关键参数。

采用外层蒙特卡罗，固定随机种子，分别输出人员、财产、环境和供气风险量的 P5/P50/P95。敏感性优先使用秩相关或 Sobol 指标；样本不足时采用单因素扰动并明确标注方法。

禁止用一个“数据质量权重”直接乘风险值。数据质量影响参数分布宽度和结果置信程度，不改变物理意义。

### 5.17 步骤 Q：措施模拟和残余风险

每项措施必须映射到可变化的模型参数，重新运行完整 QRA：

| 措施 | 主要改变参数 |
|---|---|
| 加强巡护、施工监控、警示和物防 | 第三方损坏修正函数 `K_third_party` |
| 内检测、修复、防腐层治理、阴保整改 | 腐蚀/裂纹频率或结构可靠性变量 |
| 泄漏检测和远传 | 检测时间 |
| 自动/远控切断阀、缩短阀间距 | 关阀时间和可释放库存 |
| 降压运行 | 泄漏率、后果范围，必要时也改变失效概率 |
| 迁改/改线 | 泄漏点与人口、建筑和着火源的空间关系 |
| 应急疏散和人员防护 | 社会风险人口暴露；不得降低假定全年暴露的 IR |
| 防火墙、抗爆加固、设备迁移 | 财产损坏概率和直接损失 |
| 截流、围堰、污染物收集和环境应急 | 环境影响面积、外排量和恢复时间 |
| 双气源、旁路、管存调度和备用供气 | 未供气量、停供时间和受影响用户数 |

措施效果：

```math
\Delta PLL=PLL_{baseline}-PLL_{residual}
```

```math
\Delta IR(x)=IR_{baseline}(x)-IR_{residual}(x)
```

并分别计算 `ΔEAL_asset`、`ΔE_release`、`ΔE_area`、`ΔE_recovery`、`ΔE_unserved` 和 `ΔE_customer_hours`。治理方案优先满足所有已启用后果域的强制准则，再进行 ALARP、成本效益或经批准的多准则论证。多准则权衡不能反向修改任何原始 QRA 风险量。

## 6. 频率模型切换规则

| 条件 | 频率模型 | 说明 |
|---|---|---|
| 只有运行属性和行业/企业事故统计 | 历史数据修正法 | v1 默认 |
| 有可靠 ILI 缺陷、材料、载荷和模型误差分布 | 结构可靠性法 | 适用于腐蚀、裂纹、制造缺陷等指定机理 |
| 有设备基本事件率和明确逻辑关系 | 故障树法 | 适用于控制系统、隔离失败或误操作链 |
| 数据不足以支持任何定量频率 | 阻断正式 QRA | 不允许用半定量分值伪造频率 |

模型切换按“失效机理”进行。例如外腐蚀可用结构可靠性法，第三方损坏仍用历史法；两者可以相加，但同一外腐蚀事件不能被两种模型重复计算。

## 7. 计算流程伪代码

```text
freeze(run_inputs, model_versions, parameter_libraries)
validate_applicability()
segments = segment_pipeline(all_key_attributes)

for segment s in segments:
    for mechanism k in applicable_mechanisms(s):
        method = select_exactly_one_frequency_method(s, k)
        lambda[s,k,l] = method.calculate_by_LOC(s, k, l)

    leak_points = discretize(s, initial_spacing=50m)
    repeat:
        for point p, LOC l:
            allocate_frequency(p, l)
            for weather m, direction phi, time tau:
                consequence_fields = run_phast(p,l,m,phi)
                ignition_tree = calculate_ignition_branches(...)
                for branch b:
                    f[e] = lambda[p,l] * P[m,phi,tau] * P[b]
                    p_death[e,c] = damage_model(consequence_fields, c)
                    N[e] = sum(population[c,tau] * p_death[e,c])
                    asset_loss[e] = asset_model(consequence_fields, exposed_assets)
                    environment[e] = environment_model(release, footprint, sensitive_receptors)
                    service[e] = service_model(isolation, demand, alternative_supply)
        IR = aggregate_individual_risk(f, p_death)
        FN = aggregate_social_risk(f, N)
        PLL = aggregate_expected_fatalities(f, N)
        EAL_asset = aggregate_expected_asset_loss(f, asset_loss)
        E_environment = aggregate_environment_metrics(f, environment)
        E_service = aggregate_service_metrics(f, service)
        refine_leak_points_if_not_converged()
    until convergence

run_uncertainty_and_sensitivity()
compare_each_domain_with_its_approved_criteria()
rank_segments_by_requested_basis()
build_mandatory_action_list_and_pareto_frontier()
simulate_candidate_mitigations()
write_immutable_audit_result()
```

## 9. 正式计算的阻断项

缺少以下任一公共输入时，只允许试算，不得签发正式 QRA 报告：

1. 管线中心线、里程和高程；
2. 管径、壁厚、钢级、压力、温度和天然气组分；
3. 阀室位置、隔离逻辑、检测和关阀时间；
4. 评价时点有效的工程区段属性；
5. 有来源和适用性说明的失效频率库及孔径比例；
6. 至少一年的代表性风速、风向和稳定度联合分布，或经批准的替代数据；
7. 着火源及区域活动等级；
8. 已启用后果域需要的后果模型和受体数据。

第 8 项按域展开：

- 人员域：昼夜人口栅格、平台内部实现并验证的 AQ/T 3046 对应伤害模型，或经过批准且明确符合性边界的等效实现；
- 财产域：建筑/设备清单、位置、脆弱性、维修与重置费用模型；
- 环境域：环境敏感受体、迁移路径、影响范围和恢复时间模型；
- 供气域：管网拓扑、隔离方案、需求、关键用户、替代气源和恢复时间模型。

风险接受准则按域独立配置。若某域只做计算、不做判定，可暂缺该域准则，但该域状态必须为 `CALCULATED_NOT_JUDGED`。

## 10. 参数库必须分开版本化

算法版本和参数版本不能混为一体。至少建立：

| 参数库 | 内容 |
|---|---|
| `failure_frequency_library` | 基准频率、统计时间窗、样本管长、失效定义、地区和置信区间 |
| `loc_fraction_library` | 各失效机理的小/中/大孔及破裂比例 |
| `correction_model_library` | 修正变量、函数、校准样本和适用范围 |
| `ignition_library` | 立即点火表、延迟点火源效率、活动等级规则 |
| `human_damage_model_library` | 热辐射、超压、毒性死亡概率函数 |
| `asset_damage_cost_library` | 设备/建筑脆弱性、维修、重置和直接损失参数 |
| `environment_consequence_library` | 敏感受体、影响面积、迁移和恢复参数 |
| `service_consequence_library` | 隔离、需求、未供气量、用户与恢复参数 |
| `risk_criteria_library` | 各后果域准则、适用对象、批准文件和生效日期 |

算法升级不应自动改变历史参数；参数更新也不应覆盖历史运行。

## 11. 验证与验收

### 11.1 单元校验

- 所有概率在 `[0,1]`，同一事件树分支概率和为 1；
- 孔径比例对每个机理求和为 1；
- 天气/风向和时段概率分别归一；
- 频率单位最终统一为 `/a`；
- 泄漏量不超过可释放库存；
- 安全扩散分支死亡概率为 0；
- IR 不乘人口占用率，社会风险必须使用人口；
- 场景筛除必须同时满足频率和死亡概率条件。

### 11.2 基准案例

至少建立 9 类基准案例：

1. 单泄漏点、单天气、单人口栅格的手算案例；
2. 无点火源案例，验证喷射火/闪火/VCE 概率为 0；
3. 无人口案例，验证 PLL 和 F-N 为 0，但 IR 可非 0；
4. 缩短关阀时间案例，验证泄漏量和后果不增；
5. 泄漏点 50 m、25 m、12.5 m 网格收敛案例。
6. 无暴露财产案例，验证财产 EAL 为 0，但其他域不受影响；
7. 无环境敏感受体案例，验证强制环境标志为空；
8. 存在备用气源案例，验证未供气量和用户中断小时数不增；
9. 同一区段在不同后果域排名不同的案例，验证平台不生成未经批准的总分。

### 11.3 软件验证

- 用有解析解、手算结果或公开结果的简单源项测试平台内部源项与后果模块；
- 如接入 Phast/Safeti，对相同输入进行独立交叉对比，记录模型差异及原因；外部软件结果不单独构成验收依据；
- 对软件升级前后运行同一组黄金案例；
- 人工复核至少一个完整区段的频率、事件树、IR 和 F-N 聚合；
- 输入小幅变化应引起方向合理、数量级合理的输出变化；
- 保留模型设置、输入输出和测试证据。

## 12. 当前已固定与尚待建立的内容

### 12.1 已固定

- 评价类型：QRA，不是半定量；
- 资产范围：陆上埋地高压天然气输送管道；
- 主标准：SY/T 6891.2—2020；
- 后果引用文件：AQ/T 3046—2013 正文已取得；按 SY/T 6891.2 的调用范围使用，不作为长输管道主标准；
- 默认频率模型：历史数据修正法；
- 孔径场景：5 mm、25 mm、100 mm、破裂；
- 后果执行方式：平台内部版本化计算模块；
- 外部校核：GB/T 26610.5—2022 模型交叉校核，Phast/Safeti 为可选对比工具；
- 风险度量：人员 IR/F-N/PLL、财产 EAL、环境释放/面积/恢复量、供气未供气量/用户中断小时；
- 区段排序：按后果域分别排序，超限区段强制纳入，并生成 Pareto 前沿；
- 风险控制：参数化措施前后重算；
- 不确定性：P5/P50/P95 和敏感性。

### 12.2 编码前必须完成的模型固化

`AQ/T 3046—2013 化工企业定量风险评价导则` 正文已经取得，文件缺失阻断已解除。计算框架、数据结构、事件树、频率聚合和风险聚合可以进入编码阶段；源项、扩散、火灾爆炸和人员伤害模块在实现前必须完成以下工作：

1. 建立条款—模型映射，至少覆盖泄漏场景、源项与扩散、点火事件树、热辐射、闪火、爆炸、死亡概率、IR、PLL 和 F-N；
2. 为每个模型登记公式、参数、单位、适用条件、输入输出、数值边界和不确定性；
3. 明确 AQ/T 3046 中规范性条款与资料性附录的不同地位，并记录其自身排除长输管道的范围限制；
4. 以 SY/T 6891.2 的明确调用为适用依据，只移植管道后果计算所需模型，不移植化工企业设备频率、评价单元选择或风险准则；
5. 为每个拟编码模型准备手算、解析解或黄金案例，并完成技术复核后发布首个 `model_spec` 版本。

### 12.3 正式计算前仍需补齐

1. 首版失效频率库及其适用性说明；标准给出方法框架，不提供可直接用于所有管道的统一基准频率。
2. 项目启用的各后果域风险准则文件；只计算不判定时可后补。
3. 如决定接入 Phast/Safeti，可再补充其模型设置、批处理/接口方式和授权可用性；不接入不阻断平台内部计算。
4. 启用财产、环境或供气连续性域时，对应的受体、脆弱性、成本、恢复和供气网络参数库。

## 13. 标准来源映射

- SY/T 6891.2—2020：第 5～13 章及附录 A～G；
- SY/T 6859—2020：第 3～12 章及附录 A；
- GB/T 27921—2023：第 6.1～6.6 章，特别是信息管理、模型开发、验证、不确定性和报告；
- AQ/T 3046—2013：正文已取得；按 SY/T 6891.2 的调用范围，重点映射第 8～13 章及附录 E、G、H、I，用于冻结源项、扩散、点火、暴露影响、人员伤害与风险聚合模型。附录的规范性/资料性属性必须在模型登记中保留。

AQ/T 3046 第 1 章明确排除长输管道，因此本基准不把它作为资产主标准；其适用性来自 SY/T 6891.2 第 2 章的规范性引用及第 9.1.2 条的后果计算调用。正式项目启动时仍应再次核验适用法规、标准状态和项目审批要求。

## 14. 2022/2023 年标准的模型冻结决策

标准的新旧年份不是唯一判断依据，优先级依次是：对象适用范围、评价目的、规范性引用关系、模型输出是否满足已启用后果域、最后才是发布日期。

| 文件 | 是否进入长输天然气管道 QRA 主链 | 决策 |
|---|---|---|
| GB/T 26610.1—2022 | 否 | 范围是石油化工等承压设备系统 RBI，包含装置区内及界区间压力管道，不直接覆盖长距离输送管道；用于站场设备或 RBI 子系统 |
| GB/T 26610.4—2022 | 否 | 使用通用失效概率、设备修正系数和损伤因子形成设备失效可能性，不能替代管道按 km·a 统计并按机理/孔径划分的失效频率；可用于站场承压设备 |
| GB/T 26610.5—2022 | 补充 | 可冻结为 `consequence.gb26610_5_rbi.v1`，用于介质泄漏、火灾爆炸、中毒及后果面积计算和平台内部模型交叉校核；不能单独生成完整 IR/F-N |
| DB34/T 4280—2022 | 否 | 适用于 0.1～0.4 MPa、外径 50～630 mm 的在役 PE 燃气管道，并采用分值及 `R=S×C`，属于另一对象和半定量语义 |
